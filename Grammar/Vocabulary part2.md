## 2. How to Memorise (Teacher's Methods)

| Method | Example given |
|---|---|
| **Break the word into parts** | *Exonerate* = *ex-* (out) + *onus* (burden). *Teacher's memory aid:* ex + generate ("generate an exit"). |
| **Link to a known word** | *Sinister* contains "sin" → evil. *Scrupulous* ~ careful. *Succulent* ~ "suck" → juicy. |
| **Link to an incident/brand** | *Opulent* (Opulent Mall); *Pinnacle/Apex* (institute names, both mean peak); *Swift* (car, because it is fast). |
| **Rhyme or sound** | *Chivalry*; *Taut* (as in "hot and taut"); *Arduous/Ardent*. |
| **Say it aloud and repeat** | The brain tires when learning; repeat to build the connections. |
| **Write down the ones you forget** | Keep a "danger list" and revise it first. |

> **Note:** the associations above are **memory aids**, not real etymologies. For example *exonerate* comes from Latin "to unburden" and *sinister* originally meant "left-hand" in Latin. Use them to remember, not to explain.

## 7. Word-Family Tricks

| Family | Words | Common idea |
|---|---|---|
| **-acious** | sagacious, audacious, tenacious | wise / daring / firm |
| **-matic** | phlegmatic, pragmatic, dogmatic | temperament/approach |
| **Ob- words** | oblivious, obnoxious, obsolete, obstinate, obscure | "against / away" |
| **Per- words** | pernicious, perilous, perfidy, perpetual, persistent, pervasive, persuade | through/very |
| **Re- words** | rebuke, refute, retaliate, reproach, resolve, redress | back/again |
| **Im-/In-** | impede, impertinent, inane, ingenious, innocuous | negative or "in" |
| **Pairs to separate** | **oblivion vs oblivious** (state vs unaware); **perseverance vs reverence**; **imply vs infer** (hint vs conclude); **continuity vs contiguity** | spelling traps |
| **"Rage" family** | outrageous (acts that "rage" outward), enrage, rageful | anger |
| **"Phil-/Mis-"** | philanthropy (love of humanity) ↔ misanthropy (hatred) | love vs hate |
