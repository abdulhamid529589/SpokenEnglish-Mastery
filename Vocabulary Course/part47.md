### 1. Sun Hat / সান হ্যাট

| | |
|---|---|
| **English** | Sun Hat |
| **বাংলা** | সান হ্যাট / রোদের টুপি |
| **Alternative** | Tuxedo Hat |
| **উচ্চারণ** | সান হ্যাট |

**📝 বিস্তারিত ব্যাখ্যা:**
- গরমকালে রোদ থেকে মাথা বাঁচাতে যে টুপি পরা হয়, সেটাকে **Sun Hat** বলে।
- এটি একটি বেসিক এবং সহজ শব্দ — কোর্সের শুরুতে এই সহজ শব্দটি দিয়ে শুরু করা হয়েছে।
- **Tuxedo Hat** বলতেও এই ধরনের টুপি বোঝানো যায়।

**💡 ব্যবহার:**
> *"Sunshine, sunshine with my sun hat, I'm ready for summer!"*
> রোদ, রোদ — আমার সান হ্যাট নিয়ে আমি গ্রীষ্মের জন্য প্রস্তুত!

### 2. Blazing Sunlight / প্রচণ্ড রোদ

| | |
|---|---|
| **English** | Blazing Sunlight |
| **বাংলা** | প্রচণ্ড / ঝলসানো রোদ |
| **Alternative** | Scorching Heat |
| **উচ্চারণ** | ব্লেজিং সানলাইট / স্কর্চিং হিট |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Blazing** মানে হলো "জ্বলন্ত" বা "প্রচণ্ড"। সূর্যের আলো যখন খুব তীব্র হয়, তখন বলা হয় **Blazing Sunlight**।
- **Scorching** মানেও একই — "ঝলসে দেওয়া গরম"। Scorching Heat মানে এমন গরম যা যেন পুড়িয়ে দিচ্ছে।
- দুটো শব্দই ব্যবহার করা যায় — অর্থ প্রায় একই।

**💡 ব্যবহার:**
> *"The blazing sunlight was actually hurting everyone."*
> প্রচণ্ড রোদ সবাইকে কষ্ট দিচ্ছিল।

### 3. Sweat / ঘাম

| | |
|---|---|
| **English** | Sweat |
| **বাংলা** | ঘাম |
| **Alternative (formal)** | Perspiration |
| **উচ্চারণ** | সোয়েট / পার্স্পিরেশন |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Sweat** মানে ঘাম — এটি অনেক বেশি ব্যবহৃত এবং সাধারণ শব্দ।
- **Perspiration** হলো **Sweat**-এর আনুষ্ঠানিক (formal) বিকল্প শব্দ। এটি একটু বেশি formal এবং বৈজ্ঞানিক।
- গরমের কারণে সবাই ঘামছে — এই প্রসঙ্গেই শব্দটি শেখানো হয়েছে।

| শব্দ | ব্যবহার |
|---|---|
| Sweat | সাধারণ কথায় (informal) |
| Perspiration | আনুষ্ঠানিক বা লেখায় (formal) |

**💡 ব্যবহার:**
> *"The blazing sunlight made almost everyone sweat."*
> প্রচণ্ড রোদে প্রায় সবাই ঘেমে গিয়েছিল।

---

### 4. Umbrella / ছাতা

| | |
|---|---|
| **English** | Umbrella |
| **বাংলা** | ছাতা |
| **উচ্চারণ** | আমব্রেলা |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Umbrella** মানে ছাতা। এটি বৃষ্টি এবং রোদ — উভয় ক্ষেত্রেই ব্যবহার করা হয়।
- **⚠️ গুরুত্বপূর্ণ:** Umbrella শব্দটির কোনো বিকল্প না খোঁজাই ভালো। এটিই সর্বোত্তম এবং সবচেয়ে সঠিক শব্দ।
- বাংলায় আমরা বলি "ছাতা" — ইংরেজিতে সেটাই **Umbrella**।

**💡 ব্যবহার:**
> *"A lot of people were also carrying umbrellas because of the heat."*
> গরমের কারণে অনেক মানুষ ছাতা বহন করছিল।

### 5. Hand Fan / হাতপাখা

| | |
|---|---|
| **English** | Hand Fan |
| **বাংলা** | হাতপাখা |
| **Short form** | Fan |
| **উচ্চারণ** | হ্যান্ড ফ্যান |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Hand Fan** মানে হাত দিয়ে বাতাস করার পাখা — বাংলায় যাকে আমরা বলি "হাতপাখা"।
- এটি সাধারণত বাঁশ, কাপড় বা কাগজ দিয়ে তৈরি হয়।
- **Fan** শব্দটি বৈদ্যুতিক পাখা এবং হাতপাখা উভয়কেই বোঝাতে পারে।

**💡 ব্যবহার:**
> *"A lot of people were also carrying umbrellas and hand fans because of the heat."*
> গরমের কারণে অনেক মানুষ ছাতা ও হাতপাখা বহন করছিল।

### 6. Sunshades / ছাউনি বা শেড

| | |
|---|---|
| **English** | Sunshades |
| **বাংলা** | ছাউনি / শেড / ছায়াস্থান |
| **Alternative** | Canopy |
| **উচ্চারণ** | সানশেডস / ক্যানোপি |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Sunshades** মানে এমন কোনো ছাউনি বা আচ্ছাদন যা রোদ থেকে রক্ষা করে। দোকানের সামনে বা রাস্তার পাশে যে ছাদের মতো কাঠামো থাকে, সেটা হলো Sunshades।
- **Canopy** মানেও প্রায় একই — একটি বড় ছাউনি বা তাঁবু।
- বাংলায় "চাউনি" বা "শামিয়ানা" বলা যায়।

**💡 ব্যবহার:**
> *"Some were standing in the sunshades to protect themselves from the sun."*
> কিছু মানুষ রোদ থেকে বাঁচতে ছাউনির নিচে দাঁড়িয়েছিল।

### 7. Popsicles / বরফের আইসক্রিম

| | |
|---|---|
| **English** | Popsicles |
| **বাংলা** | বরফের আইসক্রিম / কুলফি |
| **Alternative** | Ice Cream |
| **উচ্চারণ** | পপসিকেলস |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Popsicles** মানে হলো বরফের লাঠিতে গাঁথা আইসক্রিম — বাংলায় "আইস ললি" বা "কুলফি" বলতে পারি।
- **Ice Cream** শব্দটিও ব্যবহার করা যায় — এটি আরো সাধারণ এবং সবাই বোঝে।
- গরমে শিশুরা সাধারণত এই ধরনের ঠান্ডা খাবার খায়।

**💡 ব্যবহার:**
> *"Some children were enjoying summer popsicles."*
> কিছু শিশু গ্রীষ্মকালীন আইসক্রিম উপভোগ করছিল।

### 8. Sunglasses / রোদচশমা

| | |
|---|---|
| **English** | Sunglasses |
| **বাংলা** | রোদচশমা / সানগ্লাস |
| **Alternative** | Eyeglasses / Glasses |
| **উচ্চারণ** | সানগ্লাসেস |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Sunglasses** মানে রোদচশমা — চোখকে রোদের ক্ষতিকর আলো থেকে রক্ষা করতে পরা হয়।
- **Eyeglasses** বা **Glasses** বলতে যেকোনো চশমা বোঝায় — রোদচশমা বা সাধারণ চশমা উভয়ই।

> **⚠️ গুরুত্বপূর্ণ সতর্কতা (Warning):**

| শব্দ | কী বোঝায় | ব্যবহার করা যাবে? |
|---|---|---|
| **Sunglasses** | শুধু রোদচশমা | ✅ রোদচশমার জন্য সবসময় |
| **Eyeglasses** | যেকোনো চশমা (রোদ বা সাধারণ) | ✅ উভয়ের জন্য |
| **Glasses** | যেকোনো চশমা | ✅ উভয়ের জন্য |

> 🚫 **মনে রাখুন:** সাধারণ চশমাকে কখনো "Sunglasses" বলা যাবে না। কিন্তু রোদচশমাকে "Eyeglasses" বা "Glasses" বলা যায়। সঠিক থাকতে রোদচশমার জন্য **Sunglasses** শব্দটিই ব্যবহার করুন।

**💡 ব্যবহার:**
> *"I regretted not bringing my sunglasses because the sun was so strong."*
> আমি আফসোস করলাম যে আমার সানগ্লাস আনিনি, কারণ রোদ খুবই তীব্র ছিল।

### 9. Cotton Wear / সুতির পোশাক

| | |
|---|---|
| **English** | Cotton Wear |
| **বাংলা** | সুতির পোশাক |
| **Alternative** | Cotton Garments |
| **উচ্চারণ** | কটন ওয়্যার / কটন গার্মেন্টস |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Cotton Wear** মানে সুতির কাপড়ে তৈরি পোশাক। গরমে সুতির পোশাক পরলে আরাম পাওয়া যায় কারণ এটি ঘাম শোষণ করে এবং বাতাস চলাচল করতে দেয়।
- **Cotton Garments** বললেও একই অর্থ — এটিও সঠিক।
- বর্ষা মৌসুমেও সুতির পোশাক অনেক ব্যবহার হয়।

**💡 ব্যবহার:**
> *"There were many people dressed in comfortable cotton wear to stay cool in the heat."*
> গরমে ঠান্ডা থাকতে অনেকেই আরামদায়ক সুতির পোশাক পরেছিল।

### 10. Shorts / হাফপ্যান্ট

| | |
|---|---|
| **English** | Shorts |
| **বাংলা** | হাফপ্যান্ট / শর্টস |
| **Alternative** | Short Trousers |
| **উচ্চারণ** | শর্টস |

**📝 বিস্তারিত ব্যাখ্যা:**
- **Shorts** মানে হাফপ্যান্ট — হাঁটুর উপরে বা হাঁটু পর্যন্ত আসে এমন প্যান্ট।
- গরমে হালকা ও আরামদায়ক হওয়ায় অনেকেই Shorts পরেন।
- **Short Trousers** বললেও একই অর্থ বোঝায় — এটি একটু বেশি formal।

**💡 ব্যবহার:**
> *"There were many people dressed in comfortable cotton wear and shorts to stay cool in the heat."*
> গরমে ঠান্ডা থাকতে অনেকেই সুতির পোশাক ও হাফপ্যান্ট পরেছিল।

### ⚠️ সতর্কতা ১ — Sunglasses vs Eyeglasses

- **Eyeglasses / Glasses** → রোদচশমা বা সাধারণ চশমা, উভয়ের জন্য।
- সাধারণ চশমাকে কখনো **Sunglasses** বলা যাবে না ❌

---

### ⚠️ সতর্কতা ২ — Umbrella
- **Umbrella** শব্দটির অন্য কোনো বিকল্প ব্যবহার না করাই উত্তম।
- এটিই সবচেয়ে প্রচলিত এবং সঠিক শব্দ।

### ✅ টিপস — Sweat vs Perspiration
| শব্দ | ধরন | কখন ব্যবহার করবেন |
|---|---|---|
| **Sweat** | Informal (অনানুষ্ঠানিক) | কথা বলার সময় |
| **Perspiration** | Formal (আনুষ্ঠানিক) | লেখায় বা আনুষ্ঠানিক প্রসঙ্গে |
