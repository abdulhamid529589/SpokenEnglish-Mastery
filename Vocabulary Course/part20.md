In this lesson, we will learn English names of various items found in the bedroom. Along with each word, we will learn its synonyms and how to use it in a sentence.

### ১. Double Bed — বড় বিছানা

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                            |
| --------------- | -------------------------------- |
| **ইংরেজি শব্দ** | Double Bed                       |
| **উচ্চারণ**     | ডাবল বেড                         |
| **বাংলা অর্থ**  | বড় বিছানা / দুইজনের জন্য বিছানা |
| **বিকল্প শব্দ** | Large Bed                        |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Double Bed** হলো দুইজন মানুষ একসাথে ঘুমাতে পারে এমন বড় বিছানা।

A **double bed** is a large bed wide enough for two people to sleep on comfortably. It can also be called a **large bed**.

**বিছানার আকার অনুযায়ী নাম | Bed Sizes in English:**

| ইংরেজি নাম | বাংলা অর্থ     | আকার        |
| ---------- | -------------- | ----------- |
| Single Bed | একজনের বিছানা  | ছোট         |
| Double Bed | দুইজনের বিছানা | মাঝারি বড়  |
| Queen Bed  | কুইন বেড       | বড়         |
| King Bed   | কিং বেড        | সবচেয়ে বড় |

**বিছানার অংশের নাম | Parts of a Bed:**

- **Headboard** = বিছানার মাথার দিকের অংশ
- **Mattress** = গদি
- **Pillow** = বালিশ
- **Bed sheet** = বিছানার চাদর
- **Pillowcase** = বালিশের খোল

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** My pillows are always neatly stacked on my **double bed** and the duvet is kept at the other end of the bed.
> **বাংলা:** আমার বালিশগুলো সবসময় আমার **বড় বিছানায়** সুন্দরভাবে সাজানো থাকে এবং কম্বলটি বিছানার অন্য প্রান্তে রাখা থাকে।

### ২. Duvet — কম্বল / লেপ

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                        |
| --------------- | ---------------------------- |
| **ইংরেজি শব্দ** | Duvet                        |
| **উচ্চারণ**     | ডুভে (ফরাসি উচ্চারণ) / ডুভেট |
| **বাংলা অর্থ**  | লেপ / কম্বল                  |
| **বিকল্প শব্দ** | Blanket / Comforter          |
| **উৎস**         | ফরাসি ভাষা থেকে আসা শব্দ     |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Duvet** হলো একটি মোটা, নরম কম্বল বা লেপ যা ঘুমানোর সময় গায়ে দেওয়া হয়। এটি সাধারণত তুলো, পালক বা সিন্থেটিক উপাদান দিয়ে ভরা থাকে।

A **duvet** is a thick, soft blanket filled with cotton, feathers, or synthetic material, used as a bed covering. It can also be called a **blanket** or **comforter**.

> ⚠️ **গুরুত্বপূর্ণ নোট | Important Note:**
> **Duvet** শব্দটি ফরাসি ভাষা থেকে এসেছে — এটি ইংরেজিতে বহুল ব্যবহৃত হলেও উচ্চারণ একটু অপরিচিত।
> সহজে মনে রাখতে **Blanket** বা **Comforter** বলতে পারেন — একই অর্থ।

**পার্থক্য | Differences:**

| শব্দ      | বাংলা        | বৈশিষ্ট্য                                   |
| --------- | ------------ | ------------------------------------------- |
| Duvet     | লেপ/কম্বল    | মোটা, ভেতরে পুর দেওয়া                      |
| Blanket   | কম্বল        | পাতলা বা মোটা হতে পারে                      |
| Comforter | কোয়িল্ট/লেপ | আমেরিকান ইংরেজিতে বেশি ব্যবহৃত              |
| Quilt     | কাঁথা        | সেলাই করা, বিভিন্ন কাপড়ের টুকরো দিয়ে তৈরি |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** My pillows are always neatly stacked on my double bed and the **duvet** is kept at the other end of the bed.
> **বাংলা:** আমার বালিশগুলো বিছানায় সুন্দরভাবে সাজানো এবং **কম্বলটি** বিছানার অন্য প্রান্তে রাখা থাকে।

### ৩. Vanity Table — সাজার টেবিল

#### 📖 সংজ্ঞা | Definition

| বিষয়             | বিবরণ                          |
| ----------------- | ------------------------------ |
| **ইংরেজি শব্দ**   | Vanity Table                   |
| **উচ্চারণ**       | ভ্যানিটি টেবিল                 |
| **বাংলা অর্থ**    | সাজঘরের টেবিল / সাজার টেবিল    |
| **বিকল্প শব্দ**   | Dressing Table (ড্রেসিং টেবিল) |
| **অর্থ বিশ্লেষণ** | Vanity = সৌন্দর্য চর্চা        |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Vanity Table** হলো একটি টেবিল যেখানে আয়না থাকে এবং যার সামনে বসে মানুষ সাজগোজ করে, চুল আঁচড়ায় বা মেকআপ করে।

A **vanity table** is a table with a mirror at which a person sits to apply makeup, brush hair, or get ready. It is also commonly called a **dressing table**.

**Vanity Table-এ সাধারণত কী থাকে | What's Usually on a Vanity Table:**

- **Mirror** = আয়না
- **Makeup / Cosmetics** = প্রসাধনী
- **Comb / Brush** = চিরুনি / ব্রাশ
- **Perfume** = সুগন্ধি
- **Skincare products** = ত্বকের যত্নের পণ্য

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** My **vanity table** is right opposite my bed.
> **বাংলা:** আমার **সাজার টেবিলটি** বিছানার ঠিক বিপরীত দিকে আছে।

### ৪. Mirror — আয়না

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                       |
| --------------- | --------------------------- |
| **ইংরেজি শব্দ** | Mirror                      |
| **উচ্চারণ**     | মিরর                        |
| **বাংলা অর্থ**  | আয়না                       |
| **বিকল্প শব্দ** | Looking Glass (লুকিং গ্লাস) |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Mirror** হলো আয়না — যে বস্তুতে নিজের প্রতিফলন দেখা যায়।

A **mirror** is a reflective surface, typically made of glass, in which you can see your own reflection. It can also be called a **looking glass** — though this term is old-fashioned and literary.

**আয়নার ধরন | Types of Mirrors:**

| ইংরেজি             | বাংলা                     |
| ------------------ | ------------------------- |
| Full-length mirror | পুরো শরীর দেখার বড় আয়না |
| Wall mirror        | দেওয়ালে লাগানো আয়না     |
| Vanity mirror      | সাজার আয়না (টেবিলের উপর) |
| Hand mirror        | হাতে ধরার ছোট আয়না       |

> 📌 **"Looking Glass"** শব্দটি সাহিত্যে বেশি ব্যবহৃত (যেমন — _Alice Through the Looking Glass_)। সাধারণ কথায় **Mirror** বলাই ভালো।

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** There is a long **mirror** and a stool in my bedroom as well.
> **বাংলা:** আমার শোবার ঘরে একটি লম্বা **আয়না** এবং একটি টুলও আছে।

### ৫. Stool — ছোট চেয়ার / টুল

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                |
| --------------- | ------------------------------------ |
| **ইংরেজি শব্দ** | Stool                                |
| **উচ্চারণ**     | স্টুল                                |
| **বাংলা অর্থ**  | পিঠ-হাতল ছাড়া ছোট বসার জায়গা / টুল |
| **বিকল্প শব্দ** | Seat (সিট)                           |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Stool** হলো একটি ছোট বসার জায়গা যার কোনো পিঠ (backrest) বা হাতল (armrest) নেই।

A **stool** is a small seat without a back or armrests. It is commonly used in front of a vanity table or dressing table.

**চেয়ারের ধরন | Types of Seating:**

| ইংরেজি   | বাংলা      | বৈশিষ্ট্য                  |
| -------- | ---------- | -------------------------- |
| Stool    | টুল        | পিঠ ও হাতল নেই             |
| Chair    | চেয়ার     | পিঠ আছে, হাতল থাকতে পারে   |
| Armchair | আরামকেদারা | পিঠ ও হাতল দুটোই আছে       |
| Bench    | বেঞ্চ      | লম্বা, একাধিক জন বসতে পারে |

> ⚠️ **নোট:** ভিডিওতে "Tool" বলা হয়েছে কিন্তু সঠিক শব্দ হলো **"Stool"** — বসার ছোট পিঠবিহীন আসন।

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** There is a long mirror and a **stool** in my bedroom as well.
> **বাংলা:** আমার শোবার ঘরে একটি লম্বা আয়না এবং একটি **টুল**ও আছে।

### ৬. Study Table — পড়ার টেবিল

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ        |
| --------------- | ------------ |
| **ইংরেজি শব্দ** | Study Table  |
| **উচ্চারণ**     | স্টাডি টেবিল |
| **বাংলা অর্থ**  | পড়ার টেবিল  |
| **বিকল্প শব্দ** | Desk (ডেস্ক) |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Study Table** হলো পড়াশোনা বা কাজ করার জন্য ব্যবহৃত টেবিল। এটিকে সহজে **Desk** বলা যায়।

A **study table** is a table used for reading, writing, or studying. It can also simply be called a **desk**.

**ডেস্ক সম্পর্কিত শব্দ | Desk-Related Vocabulary:**

- **Desk lamp** = টেবিল বাতি
- **Bookshelf / Bookcase** = বইয়ের তাক
- **Stationery** = কলম-পেন্সিল-রুলার ইত্যাদি লেখার সামগ্রী
- **Notebook / Textbook** = খাতা / পাঠ্যবই
- **Laptop / Computer** = ল্যাপটপ / কম্পিউটার

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Right beside my bed is my **study table**.
> **বাংলা:** আমার বিছানার ঠিক পাশেই আমার **পড়ার টেবিল** আছে।

### ৭. Desk Lamp — টেবিল বাতি

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                      |
| --------------- | -------------------------- |
| **ইংরেজি শব্দ** | Desk Lamp                  |
| **উচ্চারণ**     | ডেস্ক ল্যাম্প              |
| **বাংলা অর্থ**  | টেবিলের উপর রাখার ছোট বাতি |
| **বিকল্প শব্দ** | Table Lamp (টেবিল ল্যাম্প) |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Desk Lamp** হলো পড়ার টেবিলে বা কাজের জায়গায় রাখা ছোট বাতি যা নির্দিষ্ট জায়গায় আলো দেয়।

A **desk lamp** is a small light placed on a study table or work desk to provide focused light for reading or working. It can also be called a **table lamp**.

**ঘরের বিভিন্ন ধরনের আলো | Types of Lights in a Room:**

| ইংরেজি                 | বাংলা                   |
| ---------------------- | ----------------------- |
| Ceiling light          | ছাদের বাতি              |
| Desk lamp / Table lamp | টেবিলের বাতি            |
| Floor lamp             | মেঝেতে রাখার লম্বা বাতি |
| Night light            | রাতের ছোট আলো           |
| Chandelier             | ঝাড়বাতি                |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** On my study table, I keep a **desk lamp** for reading at night.
> **বাংলা:** আমার পড়ার টেবিলে রাতে পড়ার জন্য একটি **টেবিল বাতি** রাখি।

### ৮. Wardrobe — আলমারি / ওয়ার্ডরোব

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                               |
| --------------- | ----------------------------------- |
| **ইংরেজি শব্দ** | Wardrobe                            |
| **উচ্চারণ**     | ওয়ার্ডরোব                          |
| **বাংলা অর্থ**  | কাপড়ের বড় আলমারি                  |
| **বিকল্প শব্দ** | Cupboard / Closet (আমেরিকান ইংরেজি) |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Wardrobe** হলো একটি বড়, লম্বা আলমারি যেখানে কাপড়, জুতা ও অন্যান্য জিনিস ঝুলিয়ে বা ভাঁজ করে রাখা হয়।

A **wardrobe** is a large, tall cabinet or cupboard used for storing clothes, shoes, and accessories. It can be called a **cupboard** (British English) or a **closet** (American English).

**British vs American English:**

- 🇬🇧 **Wardrobe / Cupboard** — ব্রিটিশ ইংরেজি
- 🇺🇸 **Closet** — আমেরিকান ইংরেজি

**Wardrobe সম্পর্কিত শব্দ | Wardrobe-Related Vocabulary:**

- **Hanger** = কাপড় ঝোলানোর হুক
- **Shelf (inside wardrobe)** = আলমারির ভেতরের তাক
- **Drawer** = টানা বাক্স
- **Door / Mirror door** = দরজা / আয়না দরজা

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** I also have a tall **wardrobe** and a small chest of drawers on the other side.
> **বাংলা:** অন্য পাশে আমার একটি লম্বা **আলমারি** এবং একটি ছোট ড্রয়ার বাক্সও আছে।

### ৯. Chest of Drawers — ড্রয়ারের বাক্স

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                           |
| --------------- | ------------------------------- |
| **ইংরেজি শব্দ** | Chest of Drawers                |
| **উচ্চারণ**     | চেস্ট অব ড্রয়ারস               |
| **বাংলা অর্থ**  | একাধিক টানা বাক্স সহ ছোট আলমারি |
| **বিকল্প শব্দ** | Drawers / Dresser               |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Chest of Drawers** হলো একটি ফার্নিচার যেখানে একাধিক টানা বাক্স (drawer) থাকে। এতে কাপড়, অন্তর্বাস, মোজা বা ছোট জিনিসপত্র রাখা হয়।

A **chest of drawers** is a piece of furniture with multiple sliding drawers used for storing folded clothes, undergarments, socks, and other small items. It can simply be called **drawers** or a **dresser**.

**Wardrobe বনাম Chest of Drawers | Wardrobe vs Chest of Drawers:**

| বিষয়   | Wardrobe           | Chest of Drawers          |
| ------- | ------------------ | ------------------------- |
| আকার    | বড়, লম্বা         | ছোট, কম উঁচু              |
| দরজা    | হ্যাঁ (দরজা আছে)   | না (টানা বাক্স আছে)       |
| ব্যবহার | ঝুলানো কাপড়, জুতা | ভাঁজ করা কাপড়, ছোট জিনিস |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** I also have a tall wardrobe and a small **chest of drawers** on the other side.
> **বাংলা:** অন্য পাশে আমার একটি লম্বা আলমারি এবং একটি ছোট **ড্রয়ার বাক্স**ও আছে।

### ১০. Rug — কার্পেট / গালিচা

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                   |
| --------------- | ----------------------- |
| **ইংরেজি শব্দ** | Rug                     |
| **উচ্চারণ**     | রাগ                     |
| **বাংলা অর্থ**  | ছোট গালিচা / মেঝের চাদর |
| **বিকল্প শব্দ** | Carpet (কার্পেট)        |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Rug** হলো মেঝেতে বিছানোর জন্য একটি ছোট বা মাঝারি আকারের গালিচা।

A **rug** is a thick fabric mat placed on the floor for warmth, comfort, or decoration. It can also be called a **carpet**, though there is a slight difference.

**Rug বনাম Carpet | Rug vs Carpet:**

| বিষয়      | Rug           | Carpet                |
| ---------- | ------------- | --------------------- |
| আকার       | ছোট বা মাঝারি | পুরো ঘরের মেঝে ঢাকে   |
| স্থায়িত্ব | সরানো যায়    | সাধারণত মেঝেতে আটকানো |
| ব্যবহার    | সাজানোর জন্যও | আরাম ও উষ্ণতার জন্য   |

> 📌 **Vintage Rug** — পুরনো ধাঁচের বা অ্যান্টিক ধরনের গালিচা (নিচে বিস্তারিত দেখুন)

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Between them and my bed is a vintage **rug** I brought with me from my China trip.
> **বাংলা:** সেগুলো এবং আমার বিছানার মাঝখানে একটি পুরনো ধাঁচের **গালিচা** আছে যেটি আমি চীন সফর থেকে এনেছিলাম।

## বিশেষ শব্দ: Vintage — পুরনো ধাঁচের

#### 📖 সংজ্ঞা | Definition

| বিষয়              | বিবরণ                           |
| ------------------ | ------------------------------- |
| **ইংরেজি শব্দ**    | Vintage                         |
| **উচ্চারণ**        | ভিন্টেজ                         |
| **বাংলা অর্থ**     | পুরনো ধাঁচের / অ্যান্টিক ধরনের  |
| **সম্পর্কিত শব্দ** | Antique (অ্যান্টিক) = খুব পুরনো |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Vintage** মানে এমন কিছু যা পুরনো কিন্তু এখনো ভালো মানের এবং ঐতিহ্যবাহী। সাধারণত ২০-১০০ বছর পুরনো জিনিসকে Vintage বলা হয়।

**Vintage** describes something that is old but of high quality, classic, and from a particular era — typically 20 to 100 years old. Items over 100 years are usually called **antique**.

**Vintage ব্যবহারের উদাহরণ | Vintage Usage Examples:**

- **Vintage rug** = পুরনো ধাঁচের গালিচা
- **Vintage car** = পুরনো আমলের গাড়ি
- **Vintage clothing** = পুরনো স্টাইলের পোশাক
- **Vintage watch** = পুরনো ঘড়ি

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Between them and my bed is a **vintage** rug I brought with me from my China trip.
> **বাংলা:** আমার বিছানার মাঝে একটি **পুরনো ধাঁচের** গালিচা আছে যা আমি চীন থেকে এনেছিলাম।

## মনে রাখার কৌশল | Memory Tips

### 🧠 শব্দ মনে রাখার সহজ উপায়

| শব্দ                 | মনে রাখার কৌশল                                        |
| -------------------- | ----------------------------------------------------- |
| **Double Bed**       | Double = দুই → দুইজনের বিছানা                         |
| **Duvet**            | "ডুভে" — ফরাসি শব্দ, মনে রাখুন **Blanket** দিয়ে      |
| **Vanity Table**     | Vanity = সৌন্দর্য → যে টেবিলে সাজা হয়                |
| **Mirror**           | বাংলায় "মিরর" হিসেবে প্রচলিত                         |
| **Stool**            | "স্কুল" এর মতো শোনায় → স্কুলের টুল                   |
| **Study Table**      | Study = পড়াশোনা → পড়ার টেবিল                        |
| **Desk Lamp**        | Desk = টেবিল, Lamp = বাতি → টেবিল বাতি                |
| **Wardrobe**         | Ward = রক্ষা করা + robe = পোশাক → পোশাক রক্ষার আলমারি |
| **Chest of Drawers** | Chest = বুক/বাক্স, Drawers = টানা বাক্স               |
| **Rug**              | "রাগ" — ছোট কার্পেট                                   |
| **Vintage**          | "পুরনো কিন্তু মূল্যবান" — পুরনো মানেই ফেলনা না!       |

### 🔑 মূল নীতি | Key Principles

- **British vs American English:** একই জিনিস দুই দেশে ভিন্ন নামে পরিচিত (Wardrobe vs Closet, Duvet vs Comforter) — দুটোই শিখুন।
- **শোবার ঘরে গিয়ে প্র্যাকটিস করুন:** ঘরে থাকা প্রতিটি জিনিসের ইংরেজি নাম বলুন।
- **বাক্যে ব্যবহার করুন:** শুধু শব্দ নয়, পুরো বাক্যে ব্যবহারের চেষ্টা করুন।
- **বিকল্প শব্দ:** প্রতিটি শব্দের অন্তত একটি বিকল্প শব্দ মনে রাখুন।
