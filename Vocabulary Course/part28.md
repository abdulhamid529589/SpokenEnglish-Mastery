### 1. Mirror / Looking Glass — আয়না

|                      |                     |
| -------------------- | ------------------- |
| **Primary Word**     | **Mirror**          |
| **Alternative Word** | **Looking Glass**   |
| **বাংলা অর্থ**       | আয়না               |
| **উচ্চারণ**          | মি-রর / লুকিং গ্লাস |

**ব্যাখ্যা (Explanation):**
বাথরুমের দেওয়ালে লাগানো আয়নাকে **mirror** বলা হয়। একে **looking glass**-ও বলা যায়। দুটো শব্দই সঠিক এবং ব্যবহারযোগ্য।

_(The mirror attached to the bathroom wall is called a **mirror**. It can also be called a **looking glass**. Both words are correct and usable.)_

**উদাহরণ বাক্য:**

> _"There is a small mirror over the wash bowl in my bathroom."_
> আমার বাথরুমে বেসিনের উপরে একটি ছোট আয়না আছে।

### 2. Wash Bowl / Sink — বেসিন

|                      |                  |
| -------------------- | ---------------- |
| **Primary Word**     | **Wash Bowl**    |
| **Alternative Word** | **Sink**         |
| **বাংলা অর্থ**       | বেসিন            |
| **উচ্চারণ**          | ওয়াশ বোল / সিংক |

**ব্যাখ্যা (Explanation):**
বাথরুমে হাত মুখ ধোয়ার জন্য যে বেসিন থাকে সেটাকে **wash bowl** বলা হয়। তবে আধুনিক ইংরেজিতে **sink** শব্দটি বেশি প্রচলিত।

_(The basin used for washing hands and face in the bathroom is called a **wash bowl**. However, in modern English, the word **sink** is more commonly used.)_

> 💡 **টিপস:** দুটো শব্দই গ্রহণযোগ্য, তবে **sink** বেশি ব্যবহৃত হয়।
> _(Both words are acceptable, but **sink** is used more frequently.)_

**উদাহরণ বাক্য:**

> _"There is a small mirror over the wash bowl in my bathroom."_
> আমার বাথরুমে সিংকের উপরে একটি ছোট আয়না আছে।

---

### 3. Bathroom Cabinet / Cupboard — বাথরুম আলমারি

|                      |                                 |
| -------------------- | ------------------------------- |
| **Primary Word**     | **Bathroom Cabinet**            |
| **Alternative Word** | **Cupboard**                    |
| **বাংলা অর্থ**       | বাথরুমের আলমারি/ক্যাবিনেট       |
| **উচ্চারণ**          | বাথ-রুম ক্যাব-ই-নেট / কাপ-বোর্ড |

**ব্যাখ্যা (Explanation):**
বাথরুমের ভেতরে যে আলমারি বা ক্যাবিনেট থাকে, যেখানে বিভিন্ন সামগ্রী রাখা হয়, তাকে **bathroom cabinet** বলা হয়।

_(The cabinet or storage unit inside the bathroom where various items are kept is called a **bathroom cabinet**.)_

**Cabinet vs Cupboard পার্থক্য:**

| Cabinet                      | Cupboard                     |
| ---------------------------- | ---------------------------- |
| দরজাবিহীন তাক / open shelves | দরজাযুক্ত আলমারি / has doors |
| উন্মুক্ত বালুচর              | বন্ধ স্থান                   |

**উদাহরণ বাক্য:**

> _"I have a small bathroom cabinet where I keep my toiletries."_
> আমার একটি ছোট বাথরুম ক্যাবিনেট আছে যেখানে আমি আমার টয়লেট্রিজ রাখি।

### 4. Toiletries — বাথরুমের প্রয়োজনীয় সামগ্রী

|                |                                |
| -------------- | ------------------------------ |
| **Word**       | **Toiletries**                 |
| **বাংলা অর্থ** | বাথরুমের প্রয়োজনীয় জিনিসপত্র |
| **উচ্চারণ**    | টয়-লেট-রিজ                    |

**ব্যাখ্যা (Explanation):**
বাথরুমে ব্যবহৃত সকল প্রয়োজনীয় জিনিসপত্রের সমষ্টিকে **toiletries** বলা হয়। এটি একটি সমষ্টিবাচক শব্দ (collective noun)।

_(All the necessary items used in the bathroom are collectively called **toiletries**. It is a collective noun.)_

**Toiletries-এর উদাহরণ (Examples of Toiletries):**

| বাংলা         | English            |
| ------------- | ------------------ |
| শ্যাম্পু      | Shampoo            |
| সাবান         | Soap               |
| ব্রাশ         | Brush / Toothbrush |
| টুথপেস্ট      | Toothpaste         |
| হ্যান্ড ওয়াশ | Hand Wash          |
| ফেস ওয়াশ     | Face Wash          |
| কসমেটিক্স     | Cosmetics          |

**উদাহরণ বাক্য:**

> _"I have a small bathroom cabinet where I keep my toiletries."_
> আমার একটি ছোট বাথরুম ক্যাবিনেট আছে যেখানে আমি আমার টয়লেট্রিজ রাখি।

### 5. Face Wash / Cleanser — ফেস ওয়াশ

|                      |                          |
| -------------------- | ------------------------ |
| **Primary Word**     | **Face Wash**            |
| **Alternative Word** | **Cleanser**             |
| **বাংলা অর্থ**       | মুখ পরিষ্কার করার উপাদান |
| **উচ্চারণ**          | ফেস ওয়াশ / ক্লেন-জার    |

**ব্যাখ্যা (Explanation):**
মুখ ধোয়ার জন্য যে জিনিস ব্যবহার করা হয় তাকে **face wash** বলা হয়। এটাকে **cleanser**-ও বলা যায়। দুটো শব্দের অর্থ একই।

_(The product used to wash the face is called a **face wash**. It can also be called a **cleanser**. Both words have the same meaning.)_

> 💡 **মনে রাখুন:** Face wash এবং Cleanser — উভয়ই মুখ পরিষ্কার করতে ব্যবহৃত হয়।
> _(Remember: Both face wash and cleanser are used to clean the face.)_

**উদাহরণ বাক্য:**

> _"There's also a rack where I keep my face wash, comb, some detergent and extra toilet paper."_
> একটি র‍্যাকও আছে যেখানে আমি আমার ফেস ওয়াশ, চিরুনি, কিছু ডিটারজেন্ট এবং অতিরিক্ত টয়লেট পেপার রাখি।

### 6. Comb / Hairbrush — চিরুনি

|                      |                    |
| -------------------- | ------------------ |
| **Primary Word**     | **Comb**           |
| **Alternative Word** | **Hairbrush**      |
| **বাংলা অর্থ**       | চিরুনি             |
| **উচ্চারণ**          | কোম / হেয়ার-ব্রাশ |

**ব্যাখ্যা (Explanation):**
চুল আঁচড়ানোর জন্য ব্যবহৃত জিনিসকে **comb** বা **hairbrush** বলা হয়। পছন্দ অনুযায়ী যেকোনোটি ব্যবহার করা যায়।

_(The tool used for combing hair is called a **comb** or **hairbrush**. Either can be used according to preference.)_

**উদাহরণ বাক্য:**

> _"There's also a rack where I keep my face wash, comb..."_
> একটি র‍্যাকও আছে যেখানে আমি আমার ফেস ওয়াশ, চিরুনি রাখি...

### 7. Detergent / Soap — ডিটারজেন্ট

|                      |                           |
| -------------------- | ------------------------- |
| **Primary Word**     | **Detergent**             |
| **Alternative Word** | **Soap** (সীমিত ক্ষেত্রে) |
| **বাংলা অর্থ**       | ডিটারজেন্ট / পরিষ্কারক    |
| **উচ্চারণ**          | ডি-টার-জেন্ট              |

**ব্যাখ্যা (Explanation):**
কাপড় বা অন্যান্য জিনিস পরিষ্কার করার জন্য ব্যবহৃত রাসায়নিক পদার্থকে **detergent** বলা হয়।

_(The chemical substance used for cleaning clothes or other things is called **detergent**.)_

> ⚠️ **গুরুত্বপূর্ণ সতর্কতা | Important Warning:**
> **Soap** এবং **Detergent** সব ক্ষেত্রে একসাথে ব্যবহার করা যাবে না!
>
> | Soap                      | Detergent                     |
> | ------------------------- | ----------------------------- |
> | গোসলের সাবান বোঝায়       | কাপড় ধোয়ার রাসায়নিক বোঝায় |
> | শরীর পরিষ্কারে ব্যবহৃত    | কাপড় পরিষ্কারে ব্যবহৃত       |
> | হাত দিয়ে ব্যবহার করা হয় | সাধারণত পানিতে মেশানো হয়     |
>
> _(Soap and Detergent cannot be used interchangeably in all situations!)_

**উদাহরণ বাক্য:**

> _"There's also a rack where I keep... some detergent and extra toilet paper."_

### 8. Toilet Paper / Toilet Tissue Roll — টয়লেট পেপার

|                      |                                    |
| -------------------- | ---------------------------------- |
| **Primary Word**     | **Toilet Paper**                   |
| **Alternative Word** | **Toilet Tissue Roll**             |
| **বাংলা অর্থ**       | টয়লেট পেপার                       |
| **উচ্চারণ**          | টয়-লেট পেই-পার / টয়-লেট টিশু রোল |

**ব্যাখ্যা (Explanation):**
বাথরুমে ব্যবহৃত কাগজের রোলকে **toilet paper** বা **toilet tissue roll** বলা হয়। দুটোই সঠিক।

_(The paper roll used in the bathroom is called **toilet paper** or **toilet tissue roll**. Both are correct.)_

**উদাহরণ বাক্য:**

> _"There's also a rack where I keep my face wash, comb, some detergent and extra toilet paper."_
> একটি র‍্যাক আছে যেখানে আমি ফেস ওয়াশ, চিরুনি, ডিটারজেন্ট এবং অতিরিক্ত টয়লেট পেপার রাখি।

### 9. Scales / Weighing Machine — দাঁড়িপাল্লা / ওজন মাপার যন্ত্র

|                      |                              |
| -------------------- | ---------------------------- |
| **Primary Word**     | **Scales** (Bathroom Scales) |
| **Alternative Word** | **Weighing Machine**         |
| **বাংলা অর্থ**       | ওজন মাপার যন্ত্র             |
| **উচ্চারণ**          | স্কেইলজ / ওয়েইং মেশিন       |

**ব্যাখ্যা (Explanation):**
শরীরের ওজন মাপার যন্ত্রকে **bathroom scales** বা **weighing machine** বলা হয়।

_(The device used to measure body weight is called **bathroom scales** or **weighing machine**.)_

**উদাহরণ বাক্য:**

> _"I also have bathroom scales to measure my weight occasionally."_
> মাঝে মাঝে ওজন মাপার জন্য আমার কাছে ব্যাথরুম স্কেলসও আছে।

### 10. Towel / Drying Cloth — তোয়ালে

|                      |                        |
| -------------------- | ---------------------- |
| **Primary Word**     | **Towel**              |
| **Alternative Word** | **Drying Cloth**       |
| **বাংলা অর্থ**       | তোয়ালে                |
| **উচ্চারণ**          | টাউ-এল / ড্রাই-ইং ক্লথ |

**ব্যাখ্যা (Explanation):**
হাত, মুখ বা শরীর মোছার কাপড়কে **towel** বলা হয়। **Drying cloth**-ও বলা যায়, তবে **towel** শব্দটি বেশি প্রচলিত।

_(The cloth used to wipe hands, face, or body is called a **towel**. It can also be called a **drying cloth**, but the word **towel** is more commonly used.)_

> 💡 **টিপস:** **Towel** শব্দটি বেশি সাধারণ ও প্রচলিত, তাই এটিই ব্যবহার করা ভালো।
> _(**Towel** is more common and widely used, so it's better to use this word.)_

**উদাহরণ বাক্য:**

> _"I often leave my towel hanging over the door after bathing in my bathtub."_
> বাথটাবে গোসলের পরে আমি প্রায়ই আমার তোয়ালেটি দরজার উপর ঝুলিয়ে রাখি।

---

### 11. Bathtub / Bathing Tub — বাথটাব

|                      |                       |
| -------------------- | --------------------- |
| **Primary Word**     | **Bathtub**           |
| **Alternative Word** | **Bathing Tub**       |
| **বাংলা অর্থ**       | গোসলের বড় টব         |
| **উচ্চারণ**          | বাথ-টাব / বেইথ-ইং টাব |

**ব্যাখ্যা (Explanation):**
বাথরুমে যে বড় টব থাকে যেখানে শুয়ে বা বসে গোসল করা যায় তাকে **bathtub** বলা হয়। এটি সব বাথরুমে থাকে না।

_(The large tub in the bathroom where one can lie down or sit and bathe is called a **bathtub**. It is not found in every bathroom.)_

**উদাহরণ বাক্য:**

> _"I often leave my towel hanging over the door after bathing in my bathtub."_
> বাথটাবে গোসলের পরে আমি প্রায়ই আমার তোয়ালেটি দরজার উপর ঝুলিয়ে রাখি।

## গুরুত্বপূর্ণ নোট

### Important Notes

> ⚠️ **Soap vs Detergent:**
>
> - **Soap** = গোসলের সাবান (for body cleaning)
> - **Detergent** = কাপড় ধোয়ার রাসায়নিক (for clothes/surfaces)
> - এই দুটো শব্দ সব ক্ষেত্রে একে অপরের জায়গায় ব্যবহার করা যাবে না।
>   _(These two words cannot be used interchangeably in all situations.)_

> 💡 **Cabinet vs Cupboard:**
>
> - **Cabinet** = দরজাবিহীন তাক (open shelves, no door)
> - **Cupboard** = দরজাযুক্ত আলমারি (has a door)

> 💡 **Sink বেশি ব্যবহৃত:**
> **Sink** শব্দটি **Wash Bowl** এর চেয়ে বেশি প্রচলিত।
> _(The word **Sink** is more commonly used than **Wash Bowl**.)_
