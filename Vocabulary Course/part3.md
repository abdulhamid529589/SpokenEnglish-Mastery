## 1. Pretty / Beautiful — সুন্দর

**Boring word | সাধারণ শব্দ:** `Pretty` / `Beautiful` = সুন্দর

> 💡 _These words are used so often they lose impact. Use more vivid alternatives._
> _এই শব্দগুলো এতবার ব্যবহার হয় যে প্রভাব কমে যায়। আরও প্রাণবন্ত বিকল্প ব্যবহার করুন।_

| Synonym       | Pronunciation | বাংলা অর্থ                 | Nuance / ব্যবহারের পার্থক্য                                   |
| ------------- | ------------- | -------------------------- | ------------------------------------------------------------- |
| **Gorgeous**  | গর্জাস        | অত্যন্ত সুন্দর, মনোমুগ্ধকর | Strikingly beautiful — আকর্ষণীয়ভাবে সুন্দর                   |
| **Stunning**  | স্টানিং       | চমকপ্রদ সুন্দর             | So beautiful it surprises you — এতটাই সুন্দর যে অবাক হয়ে যাও |
| **Ravishing** | র‍্যাভিশিং    | মুগ্ধকর সুন্দর             | Delightfully attractive — আনন্দদায়কভাবে আকর্ষণীয়            |
| **Exquisite** | এক্সকুইজিট    | অপূর্ব, নিখুঁত সুন্দর      | Beautifully detailed and perfect — সূক্ষ্ম ও নিখুঁত সৌন্দর্য  |
| **Radiant**   | রেডিয়েন্ট    | উজ্জ্বল, আলোকময় সুন্দর    | Glowing with beauty — সৌন্দর্যে উজ্জ্বল                       |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring               | ✅ Better                      |
| ----------------------- | ------------------------------ |
| "She is beautiful."     | "She is **stunning**."         |
| "সে সুন্দর।"            | "সে **চমকপ্রদ সুন্দর**।"       |
| "The flower is pretty." | "The flower is **exquisite**." |
| "ফুলটি সুন্দর।"         | "ফুলটি **অপূর্ব**।"            |

## 2. Smart — চালাক / বুদ্ধিমান

**Boring word | সাধারণ শব্দ:** `Smart` = চালাক, বুদ্ধিমান

| Synonym          | Pronunciation | বাংলা অর্থ          | Nuance / ব্যবহারের পার্থক্য                                   |
| ---------------- | ------------- | ------------------- | ------------------------------------------------------------- |
| **Witty**        | উইটি          | রসিক, তীক্ষ্ণবুদ্ধি | Clever with humor — হাস্যরসের সাথে চালাক                      |
| **Bright**       | ব্রাইট        | মেধাবী, বুদ্ধিমান   | Generally intelligent — সাধারণভাবে মেধাবী                     |
| **Intelligent**  | ইন্টেলিজেন্ট  | বুদ্ধিমান           | High mental ability — উচ্চ মানসিক ক্ষমতাসম্পন্ন               |
| **Quick-witted** | কুইক-উইটেড    | তাৎক্ষণিক বুদ্ধিমান | Fast at thinking and responding — দ্রুত চিন্তা ও সাড়া দেওয়া |
| **Sharp**        | শার্প         | তীক্ষ্ণবুদ্ধি       | Mentally keen and alert — মানসিকভাবে সজাগ ও তীক্ষ্ণ           |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring              | ✅ Better                     |
| ---------------------- | ----------------------------- |
| "He is smart."         | "He is **quick-witted**."     |
| "সে চালাক।"            | "সে **তাৎক্ষণিক বুদ্ধিমান**।" |
| "She is a smart girl." | "She is a **bright** girl."   |
| "সে একটি চালাক মেয়ে।" | "সে একটি **মেধাবী** মেয়ে।"   |

## 3. Big — বড়

**Boring word | সাধারণ শব্দ:** `Big` = বড়

| Synonym      | Pronunciation | বাংলা অর্থ         | Nuance / ব্যবহারের পার্থক্য                              |
| ------------ | ------------- | ------------------ | -------------------------------------------------------- |
| **Enormous** | ইনর্মাস       | বিশাল, অত্যন্ত বড় | Extremely large in size — আকারে অত্যন্ত বড়              |
| **Massive**  | ম্যাসিভ       | প্রকাণ্ড, বিশাল    | Very large and heavy — অনেক বড় এবং ভারী                 |
| **Gigantic** | জাইগ্যান্টিক  | দৈত্যাকার, অতিকায় | Giant-sized — দৈত্যের মতো বড়                            |
| **Immense**  | ইমেন্স        | অসীম, বিরাট        | Huge, hard to measure — বিশাল, পরিমাপ করা কঠিন           |
| **Colossal** | কলোসাল        | অতিকায়, প্রকাণ্ড  | Exceptionally large — অসাধারণভাবে বড়                    |
| **Vast**     | ভাস্ট         | বিস্তীর্ণ, বিশাল   | Very wide or large in area — এলাকায় অনেক বড় বা প্রশস্ত |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring             | ✅ Better                      |
| --------------------- | ------------------------------ |
| "It is a big house."  | "It is a **massive** house."   |
| "এটি একটি বড় বাড়ি।" | "এটি একটি **প্রকাণ্ড** বাড়ি।" |
| "The tree is big."    | "The tree is **enormous**."    |
| "গাছটি বড়।"          | "গাছটি **বিশাল**।"             |

## 4. Little — ছোট

**Boring word | সাধারণ শব্দ:** `Little` = ছোট, অল্প

| Synonym        | Pronunciation | বাংলা অর্থ              | Nuance / ব্যবহারের পার্থক্য                                        |
| -------------- | ------------- | ----------------------- | ------------------------------------------------------------------ |
| **Tiny**       | টাইনি         | ক্ষুদ্র, অতি ছোট        | Very small — অনেক ছোট                                              |
| **Diminutive** | ডিমিনিউটিভ    | ক্ষুদ্রকায়             | Notably small, often for people/things — আকারে উল্লেখযোগ্যভাবে ছোট |
| **Minuscule**  | মিনিউস্কিউল   | অতি ক্ষুদ্র             | Extremely tiny — অত্যন্ত ক্ষুদ্র                                   |
| **Miniature**  | মিনিয়েচার    | ক্ষুদ্রাকার, মিনিয়েচার | A smaller version of something — কোনো কিছুর ছোট সংস্করণ            |
| **Minute**     | মাইনিউট       | সূক্ষ্ম, অতি ছোট        | Extremely small, almost invisible — অত্যন্ত ছোট, প্রায় অদৃশ্য     |

> ⚠️ **Note | নোট:** "Minute" as a synonym for tiny is pronounced **my-NYOOT** (not "minit" like the time unit).
> "Minute" যখন ছোট অর্থে ব্যবহার হয় তখন উচ্চারণ **মাই-নিউট** (সময়ের "মিনিট" নয়)।

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring               | ✅ Better                        |
| ----------------------- | -------------------------------- |
| "It is a little bug."   | "It is a **minuscule** bug."     |
| "এটি একটি ছোট পোকা।"    | "এটি একটি **অতি ক্ষুদ্র** পোকা।" |
| "She has little hands." | "She has **tiny** hands."        |
| "তার ছোট হাত আছে।"      | "তার **ক্ষুদ্র** হাত আছে।"       |

## 5. Funny — মজাদার / হাসির

**Boring word | সাধারণ শব্দ:** `Funny` = মজাদার, হাসির

| Synonym        | Pronunciation | বাংলা অর্থ                | Nuance / ব্যবহারের পার্থক্য                                                    |
| -------------- | ------------- | ------------------------- | ------------------------------------------------------------------------------ |
| **Humorous**   | হিউমারাস      | হাস্যরসপূর্ণ              | Generally funny, with wit — সাধারণভাবে মজাদার ও রসিক                           |
| **Hilarious**  | হিলেরিয়াস    | অত্যন্ত মজাদার, খুব হাসির | Extremely funny — অত্যন্ত মজাদার                                               |
| **Hysterical** | হিস্টেরিক্যাল | পেট ব্যথা করে হাসানো মজার | So funny it causes uncontrollable laughter — এতটাই মজার যে হাসি থামানো যায় না |
| **Amusing**    | অ্যামিউজিং    | আনন্দদায়ক, মনোরঞ্জক      | Pleasantly funny or entertaining — আনন্দদায়কভাবে মজাদার                       |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring                | ✅ Better                            |
| ------------------------ | ------------------------------------ |
| "The movie was funny."   | "The movie was **hilarious**."       |
| "সিনেমাটি মজাদার ছিল।"   | "সিনেমাটি **অত্যন্ত মজাদার** ছিল।"   |
| "He told a funny story." | "He told a **humorous** story."      |
| "সে একটি মজার গল্প বলল।" | "সে একটি **হাস্যরসপূর্ণ** গল্প বলল।" |

## 6. Laughed — হাসা

**Boring word | সাধারণ শব্দ:** `Laughed` = হাসল

> 💡 _English has many specific words for different types of laughter — each tells HOW someone laughed, not just that they laughed._
> _ইংরেজিতে বিভিন্ন ধরনের হাসির জন্য নির্দিষ্ট শব্দ আছে — প্রতিটি বলে কীভাবে হাসা হয়েছে, শুধু যে হাসা হয়েছে তা নয়।_

| Synonym      | Pronunciation | বাংলা অর্থ            | How it sounds / কেমন হাসি                                              |
| ------------ | ------------- | --------------------- | ---------------------------------------------------------------------- |
| **Giggled**  | গিগলড         | খিলখিল করে হাসল       | Light, playful laughter (often girls/children) — হালকা, খেলাধুলার হাসি |
| **Cackled**  | ক্যাকলড       | কিচিরমিচির করে হাসল   | Loud, sharp, unpleasant laugh — জোরে, তীক্ষ্ণ, কর্কশ হাসি              |
| **Chuckled** | চাকলড         | মৃদু হাসল, মুচকি হাসল | Quiet, gentle laugh to oneself — নিজের মনে শান্তভাবে হাসা              |
| **Chortled** | চর্টলড        | আনন্দে ফিক করে হাসল   | A mix of chuckling and snorting — খুশিতে হেসে ওঠা                      |
| **Sneered**  | স্নিয়ার্ড    | বিদ্রূপ করে হাসল      | Laughed with contempt or mockery — অবজ্ঞা বা বিদ্রূপের হাসি            |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring                  | ✅ Better                        |
| -------------------------- | -------------------------------- |
| "She laughed at the joke." | "She **giggled** at the joke."   |
| "সে কৌতুকে হাসল।"          | "সে কৌতুকে **খিলখিল করে হাসল**।" |
| "He laughed softly."       | "He **chuckled** softly."        |
| "সে আস্তে হাসল।"           | "সে **মৃদু হাসল**।"              |

## 7. Saw — দেখা

**Boring word | সাধারণ শব্দ:** `Saw` = দেখলাম

> 💡 _Each synonym tells HOW or HOW CAREFULLY something was seen._
> _প্রতিটি প্রতিশব্দ বলে কীভাবে বা কতটা মনোযোগ দিয়ে দেখা হয়েছে।_

| Synonym      | Pronunciation | বাংলা অর্থ             | Nuance / ব্যবহারের পার্থক্য                                                 |
| ------------ | ------------- | ---------------------- | --------------------------------------------------------------------------- |
| **Glimpsed** | গ্লিম্পসড     | এক ঝলক দেখলাম          | Saw briefly, only for a moment — মাত্র এক মুহূর্তের জন্য দেখা               |
| **Noticed**  | নোটিসড        | লক্ষ্য করলাম           | Became aware of something — কোনো কিছু সম্পর্কে সচেতন হওয়া                  |
| **Observed** | অবজার্ভড      | পর্যবেক্ষণ করলাম       | Watched carefully with full attention — পূর্ণ মনোযোগ দিয়ে দেখা             |
| **Spotted**  | স্পটেড        | খুঁজে পেলাম, চোখে পড়ল | Saw something specific among many things — অনেকের মধ্যে নির্দিষ্ট কিছু দেখা |
| **Glanced**  | গ্ল্যান্সড    | এক নজর দেখলাম          | Looked quickly without much attention — দ্রুত এক নজর দেখা                   |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring                       | ✅ Better                                |
| ------------------------------- | ---------------------------------------- |
| "I saw him in the crowd."       | "I **spotted** him in the crowd."        |
| "আমি भিড়ের মধ্যে তাকে দেখলাম।" | "আমি ভিড়ের মধ্যে তাকে **খুঁজে পেলাম**।" |
| "She saw the bird fly away."    | "She **glimpsed** the bird fly away."    |
| "সে পাখিটিকে উড়ে যেতে দেখল।"   | "সে পাখিটিকে উড়ে যেতে **এক ঝলক দেখল**।" |
| "The scientist saw the cells."  | "The scientist **observed** the cells."  |
| "বিজ্ঞানী কোষগুলো দেখলেন।"      | "বিজ্ঞানী কোষগুলো **পর্যবেক্ষণ করলেন**।" |

## 8. Walked — হাঁটা

**Boring word | সাধারণ শব্দ:** `Walked` = হাঁটল

> 💡 _Each synonym describes a completely different style or mood of walking._
> _প্রতিটি প্রতিশব্দ সম্পূর্ণ আলাদা ধরনের বা মেজাজের হাঁটা বর্ণনা করে।_

| Synonym       | Pronunciation | বাংলা অর্থ           | Style of Walking / হাঁটার ধরন                                                      |
| ------------- | ------------- | -------------------- | ---------------------------------------------------------------------------------- |
| **Strolled**  | স্ট্রোলড      | আরামে ধীরে হাঁটল     | Casual, relaxed, leisurely walking — আরামদায়ক, নিশ্চিন্তে হাঁটা                   |
| **Sauntered** | সন্টার্ড      | ধীরে সুস্থে হাঁটল    | Slow, confident, carefree walk — ধীর, আত্মবিশ্বাসী, নিশ্চিন্তে হাঁটা               |
| **Lumbered**  | লাম্বার্ড     | ভারীভাবে হাঁটল       | Heavy, slow, clumsy walk (like a bear) — ভারী, ধীর, অদক্ষ হাঁটা (ভাল্লুকের মতো)    |
| **Trudged**   | ট্রাজড        | কষ্ট করে ধীরে হাঁটল  | Slow, tired walk, often through difficulty — কষ্টে ধীরে হাঁটা, প্রায়ই বাধার মধ্যে |
| **Crept**     | ক্রেপট        | নিঃশব্দে আস্তে হাঁটল | Moved slowly and quietly, without making noise — শব্দ না করে ধীরে সরে যাওয়া       |

**Example Sentences | উদাহরণ বাক্য:**

| ❌ Boring                     | ✅ Better                            |
| ----------------------------- | ------------------------------------ |

| "সে পার্কে হাঁটল।"            | "সে পার্কে **আরামে ধীরে হাঁটল**।"    |

| "সে কাদার মধ্যে হাঁটল।"       | "সে কাদার মধ্যে **কষ্ট করে হাঁটল**।" |

| "বিড়ালটি চুপচাপ হাঁটল।"      | "বিড়ালটি **নিঃশব্দে আস্তে হাঁটল**।" |

## 10. Ran — দৌড়ানো

**Boring word | সাধারণ শব্দ:** `Ran` = দৌড়াল

> 💡 _Just like walking, running has many styles — each word paints a different picture._
> _হাঁটার মতো, দৌড়ানোরও অনেক ধরন আছে — প্রতিটি শব্দ ভিন্ন ছবি আঁকে।_

| Synonym      | Pronunciation | বাংলা অর্থ               | Style of Running / দৌড়ানোর ধরন                                             |
| ------------ | ------------- | ------------------------ | --------------------------------------------------------------------------- |
| **Sprinted** | স্প্রিন্টেড   | সর্বোচ্চ গতিতে দৌড়াল    | Ran at full speed for a short distance — স্বল্প দূরত্বে পূর্ণ গতিতে দৌড়ানো |
| **Dashed**   | ড্যাশড        | হঠাৎ দ্রুত দৌড়াল        | Ran suddenly and quickly — হঠাৎ দ্রুতগতিতে দৌড়ানো                          |
| **Bolted**   | বোল্টেড       | বিদ্যুৎগতিতে পালিয়ে গেল | Ran away very fast, like an escape — খুব দ্রুত পালিয়ে যাওয়া               |
| **Rushed**   | রাশড          | তাড়াহুড়ো করে গেল       | Moved fast because of urgency — জরুরি প্রয়োজনে দ্রুত সরে যাওয়া            |
| **Darted**   | ডার্টেড       | তীরের মতো ছুটে গেল       | Moved quickly in a sudden direction — হঠাৎ তীরের মতো ছুটে যাওয়া            |

| "সে বাস ধরতে দৌড়াল।"        | "সে বাস ধরতে **হঠাৎ দ্রুত দৌড়াল**।"          |

## How to Use Synonyms Correctly | প্রতিশব্দ সঠিকভাবে ব্যবহারের নিয়ম

> ⚠️ _Not all synonyms mean exactly the same thing. Choose based on the situation._
> _সব প্রতিশব্দের অর্থ হুবহু এক নয়। পরিস্থিতি অনুযায়ী বেছে নিন।_

**Rule 1 — Match the intensity | নিয়ম ১ — তীব্রতা মেলান:**

- "Amusing" (হালকা মজার) ≠ "Hysterical" (পেট ব্যথা করা মজার)
- Use the word that matches HOW funny/big/fast something actually was.
- শব্দটি বেছে নিন যেটা আসলে কতটা মজার/বড়/দ্রুত ছিল তার সাথে মেলে।

**Rule 2 — Match the context | নিয়ম ২ — প্রসঙ্গ মেলান:**

- "Sprinted" = sports / urgency (খেলাধুলা / জরুরি অবস্থা)
- "Bolted" = escape / fear (পালানো / ভয়)
- "Dashed" = sudden quick movement (হঠাৎ দ্রুত নড়া)

**Rule 3 — Practice one new synonym per day | নিয়ম ৩ — প্রতিদিন একটি নতুন প্রতিশব্দ অনুশীলন করুন:**
