### ১. Grater — কুরানি / কোরানি যন্ত্র

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                     |
| --------------- | ------------------------- |
| **ইংরেজি শব্দ** | Grater                    |
| **উচ্চারণ**     | গ্রেইটার                  |
| **বাংলা অর্থ**  | কুরানি / সবজি ঘষার যন্ত্র |
| **বিকল্প শব্দ** | Shredder (শ্রেডার)        |
| **ক্রিয়া রূপ** | To grate (ঘষা / কোরানো)   |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Grater** হলো একটি রান্নাঘরের যন্ত্র যা দিয়ে সবজি, পনির বা অন্যান্য খাবার ছোট ছোট টুকরো বা গুঁড়ো করা হয়।

A **grater** is a kitchen tool used to shred or grate vegetables, cheese, or other food items into small pieces or powder.

- **Grater** = যে যন্ত্র দিয়ে কোরানো বা ঘষা হয়
- **Shredder** = একই কাজ করে, তবে এই শব্দটি অফিসেও ব্যবহার হয় (কাগজ কাটার যন্ত্র)
- রান্নাঘরে **Grater** বা **Shredder** দুটোই বলা যায়

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** I was sitting in the kitchen with a **grater** in my hand.
> **বাংলা:** আমি রান্নাঘরে বসে ছিলাম, হাতে একটি **কুরানি** নিয়ে।

### ২. Rack — তাক / র‍্যাক

#### 📖 সংজ্ঞা | Definition

| বিষয়             | বিবরণ                              |
| ----------------- | ---------------------------------- |
| **ইংরেজি শব্দ**   | Rack                               |
| **উচ্চারণ**       | র‍্যাক                             |
| **বাংলা অর্থ**    | তাক / জিনিস রাখার স্তরযুক্ত কাঠামো |
| **বিকল্প শব্দ**   | Holder (হোল্ডার)                   |
| **বিশেষণ উদাহরণ** | Three-tier rack = তিন তলা র‍্যাক   |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Rack** হলো একটি কাঠামো যেখানে একাধিক স্তরে জিনিসপত্র রাখা যায়। রান্নাঘরে সবজি, মশলা, বা রান্নার সামগ্রী রাখার জন্য ব্যবহার করা হয়।

A **rack** is a framework with multiple levels or tiers for storing items. In kitchens, it is commonly used to store vegetables, spices, or other cooking items.

**গুরুত্বপূর্ণ বিশেষণ | Important Adjectives:**

- **Three-tier rack** — তিন স্তরের র‍্যাক
- **Blue rack** — নীল রঙের র‍্যাক
- **Spice rack** — মশলার র‍্যাক

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** There is a blue **three-tier rack** behind me which has tomatoes, onions and potatoes.
> **বাংলা:** আমার পিছনে একটি নীল **তিন স্তরের র‍্যাক** আছে যেখানে টমেটো, পেঁয়াজ এবং আলু রাখা আছে।

### ৩. Trash Can — আবর্জনার বালতি

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                |
| --------------- | ------------------------------------ |
| **ইংরেজি শব্দ** | Trash Can / Trash Basket             |
| **উচ্চারণ**     | ট্র্যাশ ক্যান                        |
| **বাংলা অর্থ**  | আবর্জনার বালতি / ডাস্টবিন            |
| **বিকল্প শব্দ** | Waste Basket / Dustbin / Garbage Can |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Trash Can** হলো আবর্জনা ফেলার পাত্র। এটিকে **Waste Basket** বা **Dustbin**-ও বলা যায়।

A **trash can** (or **trash basket**) is a container used to discard waste or garbage. It can also be called a **waste basket**, **dustbin**, or **garbage can**.

**বিভিন্ন দেশে ভিন্ন নাম | Names in Different English-Speaking Countries:**

- 🇺🇸 আমেরিকায়: **Trash Can / Garbage Can**
- 🇬🇧 ব্রিটেনে: **Dustbin / Rubbish Bin**
- সাধারণ ইংরেজিতে: **Waste Basket**

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** There is a blue **trash can** beside the rack.
> **বাংলা:** র‍্যাকের পাশে একটি নীল **আবর্জনার বালতি** আছে।

### ৪. Water Filter — পানির ফিল্টার

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                   |
| --------------- | --------------------------------------- |
| **ইংরেজি শব্দ** | Water Filter                            |
| **উচ্চারণ**     | ওয়াটার ফিল্টার                         |
| **বাংলা অর্থ**  | পানির ফিল্টার / পানি বিশুদ্ধকারী যন্ত্র |
| **বিকল্প শব্দ** | Water Purifier (ওয়াটার পিউরিফায়ার)    |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Water Filter** হলো এমন একটি যন্ত্র যা পানিকে পরিশুদ্ধ করে পান করার উপযোগী করে তোলে।

A **water filter** is a device that purifies water and makes it safe for drinking. It can also be called a **water purifier**.

- **Filter** = ছাঁকনি (কিছু একটা দিয়ে ময়লা আলাদা করা)
- **Purifier** = পরিশোধক (সম্পূর্ণভাবে পরিষ্কার করা)

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** On the other side of the rack is our **water filter**.
> **বাংলা:** র‍্যাকের অপর পাশে আমাদের **পানির ফিল্টার** আছে।

### ৫. Kitchen Cabinet — রান্নাঘরের আলমারি / শেলফ

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                |
| --------------- | ------------------------------------ |
| **ইংরেজি শব্দ** | Kitchen Cabinet                      |
| **উচ্চারণ**     | কিচেন ক্যাবিনেট                      |
| **বাংলা অর্থ**  | রান্নাঘরের আলমারি বা বাক্সের মতো তাক |
| **বিকল্প শব্দ** | Shelf (শেলফ)                         |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Kitchen Cabinet** হলো রান্নাঘরের দেওয়ালে বা মেঝেতে লাগানো আলমারি বা বাক্স যেখানে রান্নার সামগ্রী, বাসনপত্র বা মশলা সংরক্ষণ করা হয়।

A **kitchen cabinet** is a built-in or freestanding cupboard or storage unit in a kitchen used to store cooking utensils, dishes, food, and spices. It can simply be called a **shelf**.

**Cabinet এর প্রকারভেদ | Types of Cabinets:**

- **Upper cabinet** = উপরের আলমারি (দেওয়ালে লাগানো)
- **Lower cabinet** = নিচের আলমারি (মেঝের কাছে)
- **Open shelf** = খোলা তাক

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Inside the **kitchen cabinet** at the top, I have stored all my cooking ingredients including different types of masala.
> **বাংলা:** উপরের **রান্নাঘরের আলমারির** ভেতরে আমি বিভিন্ন ধরনের মশলাসহ আমার সমস্ত রান্নার সামগ্রী সংরক্ষণ করেছি।

### ৬. Spices / Masala — মশলা

#### 📖 সংজ্ঞা | Definition

| বিষয়              | বিবরণ                                      |
| ------------------ | ------------------------------------------ |
| **ইংরেজি শব্দ**    | Spices                                     |
| **উচ্চারণ**        | স্পাইসেস                                   |
| **বাংলা অর্থ**     | মশলা                                       |
| **বিকল্প শব্দ**    | Masala (মাশলা) — বাংলা/হিন্দি উৎস থেকে     |
| **সম্পর্কিত শব্দ** | Seasoning (সিজনিং) = স্বাদ বাড়ানোর উপাদান |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Spices** হলো রান্নায় স্বাদ ও গন্ধ যোগ করার জন্য ব্যবহৃত উপাদান। বাংলায় এগুলিকে **মশলা** বলা হয়।

**Spices** are natural substances derived from plants — seeds, roots, bark, berries, or flowers — used to flavor and enhance the taste and aroma of food. In Bengali/South Asian cooking, these are commonly referred to as **masala**.

**সাধারণ মশলার নাম | Common Spice Names:**
| বাংলা | ইংরেজি |
|-------|--------|
| হলুদ | Turmeric |
| জিরা | Cumin |
| ধনিয়া | Coriander |
| মরিচ | Chili / Pepper |
| এলাচ | Cardamom |
| দারুচিনি | Cinnamon |
| লবঙ্গ | Clove |
| আদা | Ginger |
| রসুন | Garlic |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Inside the kitchen cabinet at the top, I have stored all my cooking ingredients including different types of **masala / spices**.
> **বাংলা:** উপরের রান্নাঘরের আলমারির ভেতরে আমি বিভিন্ন ধরনের **মশলা**সহ সমস্ত রান্নার সামগ্রী রেখেছি।

### ৭. Saucepan — সস প্যান / কড়াই

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                   |
| --------------- | --------------------------------------- |
| **ইংরেজি শব্দ** | Saucepan                                |
| **উচ্চারণ**     | সসপ্যান                                 |
| **বাংলা অর্থ**  | ছোট হাঁড়ি / সস রান্নার পাত্র           |
| **বিকল্প শব্দ** | Pan (প্যান)                             |
| **বিশেষত্ব**    | সাধারণত হাতল (handle) যুক্ত, গভীর পাত্র |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Saucepan** হলো একটি গভীর, সাধারণত গোলাকার রান্নার পাত্র যার একটি লম্বা হাতল থাকে। এটি সস, স্যুপ বা তরল রান্নার জন্য ব্যবহার করা হয়।

A **saucepan** is a deep, round cooking pot with a long handle, typically used for making sauces, soups, boiling liquids, or cooking small portions.

**Pan এবং Saucepan এর পার্থক্য | Difference:**

- **Pan** = চ্যাপ্টা, হাতলযুক্ত (flat, with handle) — ভাজার জন্য
- **Saucepan** = গভীর, হাতলযুক্ত (deep, with handle) — সিদ্ধ করার জন্য
- **Pot** = বড়, দুই হাতলযুক্ত (large, with two handles) — বড় রান্নার জন্য

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** **Saucepans** are neatly stored away in this cabinet.
> **বাংলা:** **সস প্যানগুলো** এই আলমারিতে সুন্দরভাবে সাজিয়ে রাখা আছে।

### ৮. Gas Stove — গ্যাসের চুলা

#### 📖 সংজ্ঞা | Definition

| বিষয়              | বিবরণ                           |
| ------------------ | ------------------------------- |
| **ইংরেজি শব্দ**    | Gas Stove                       |
| **উচ্চারণ**        | গ্যাস স্টোভ                     |
| **বাংলা অর্থ**     | গ্যাসের চুলা                    |
| **বিকল্প শব্দ**    | Cooker (কুকার) / Gas Cooker     |
| **সম্পর্কিত শব্দ** | Electric Stove = বৈদ্যুতিক চুলা |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Gas Stove** হলো গ্যাসের সাহায্যে আগুন জ্বালিয়ে রান্না করার চুলা।

A **gas stove** is a cooking appliance that uses gas as fuel to produce flames for cooking. It can also be called a **cooker** or **gas cooker**.

**বিভিন্ন ধরনের চুলা | Types of Stoves/Cookers:**
| ইংরেজি | বাংলা |
|--------|-------|
| Gas Stove | গ্যাসের চুলা |
| Electric Stove | বৈদ্যুতিক চুলা |
| Induction Cooker | ইন্ডাকশন কুকার |
| Wood/Clay Stove | মাটির চুলা |
| Kerosene Stove | কেরোসিনের চুলা |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Beneath the cabinet, there is a **gas stove** on the right.
> **বাংলা:** আলমারির নিচে, ডান পাশে একটি **গ্যাসের চুলা** আছে।

### ৯. Kitchen Sink — রান্নাঘরের বেসিন

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                     |
| --------------- | ----------------------------------------- |
| **ইংরেজি শব্দ** | Kitchen Sink                              |
| **উচ্চারণ**     | কিচেন সিংক                                |
| **বাংলা অর্থ**  | রান্নাঘরের বেসিন / হাত-বাসন ধোয়ার জায়গা |
| **বিকল্প শব্দ** | Basin (বেসিন)                             |
| **ব্যবহার**     | হাত ধোয়া, বাসন ধোয়া, সবজি ধোয়া         |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Kitchen Sink** হলো রান্নাঘরে বসানো একটি বেসিন যেখানে হাত ধোয়া, বাসন ধোয়া বা সবজি পরিষ্কার করা হয়।

A **kitchen sink** is a fixed basin installed in the kitchen, used for washing hands, dishes, vegetables, and other food items. It can also simply be called a **basin**.

**Sink সম্পর্কিত শব্দ | Related Vocabulary:**

- **Faucet / Tap** = কল (water tap)
- **Drain** = নিষ্কাশন পথ (water outlet)
- **Soap** = সাবান
- **Dish soap** = বাসন ধোয়ার সাবান

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Next to the stove is my **kitchen sink** where I wash my hands with soap before and after cooking.
> **বাংলা:** চুলার পাশে আমার **রান্নাঘরের বেসিন** আছে যেখানে আমি রান্নার আগে ও পরে সাবান দিয়ে হাত ধুই।

### ১০. Cooking Pots — রান্নার হাঁড়ি-পাতিল

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                  |
| --------------- | -------------------------------------- |
| **ইংরেজি শব্দ** | Cooking Pots                           |
| **উচ্চারণ**     | কুকিং পটস                              |
| **বাংলা অর্থ**  | রান্নার হাঁড়ি-পাতিল / বড় পাত্র       |
| **বিকল্প শব্দ** | Pots (পটস) — সাধারণভাবে                |
| **বিশেষত্ব**    | সাধারণত বড় আকারের হয়, দুটি হাতল থাকে |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Cooking Pots** হলো বড় রান্নার পাত্র যা বিরিয়ানি, ডাল, বা বড় পরিমাণে রান্নার জন্য ব্যবহার করা হয়।

**Cooking pots** are large vessels used to cook big batches of food such as rice, dal, curries, or biriyani. They are typically deeper and larger than saucepans.

**রান্নাঘরের পাত্রের ধরন | Types of Cooking Vessels:**
| ইংরেজি | বাংলা |
|--------|-------|
| Cooking Pot | বড় হাঁড়ি |
| Saucepan | ছোট হাঁড়ি / সস প্যান |
| Frying Pan | ভাজার প্যান |
| Wok | কড়াই (চাইনিজ স্টাইল) |
| Pressure Cooker | প্রেশার কুকার |
| Casserole | ক্যাসেরোল (ওভেনের জন্য) |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Inside the cabinet, underneath the stove, I have stored all my bigger **cooking pots**.
> **বাংলা:** আলমারির ভেতরে, চুলার নিচে, আমি আমার সমস্ত বড় **রান্নার হাঁড়ি-পাতিল** রেখেছি।

## মনে রাখার কৌশল | Memory Tips

### 🧠 শব্দ মনে রাখার সহজ উপায়

| শব্দ                | মনে রাখার কৌশল                                        |
| ------------------- | ----------------------------------------------------- |
| **Grater**          | "Grate" মানে ঘষা → যা দিয়ে ঘষা হয় = Grater          |
| **Rack**            | বাংলায় "র‍্যাক" হিসেবেই প্রচলিত                      |
| **Trash Can**       | Trash = আবর্জনা, Can = বালতি/পাত্র                    |
| **Water Filter**    | Water = পানি, Filter = ছাঁকনি                         |
| **Kitchen Cabinet** | Cabinet = আলমারি, Kitchen Cabinet = রান্নাঘরের আলমারি |
| **Spices**          | "মশলা" কে ইংরেজিতে Spices বলে                         |
| **Saucepan**        | Sauce + Pan = সস রান্নার প্যান                        |
| **Gas Stove**       | Gas = গ্যাস, Stove = চুলা                             |
| **Kitchen Sink**    | Sink = ডুবে যাওয়া → পানি নামে যে বেসিনে              |
| **Cooking Pots**    | Cooking = রান্না, Pots = পাতিল                        |

### 🔑 মূল নীতি | Key Rules

- **একই বস্তু, একাধিক নাম:** ইংরেজিতে একই জিনিসের বিভিন্ন নাম থাকতে পারে — দুটোই গ্রহণযোগ্য।
- **বিকল্প শব্দ শিখুন:** শুধু একটি শব্দ নয়, বিকল্পগুলোও শিখুন — এটি কথাবার্তায় বেশি সাহায্য করে।
- **বাক্যে ব্যবহার করুন:** শুধু শব্দ না শিখে, প্রতিদিন বাক্যে ব্যবহার করার চেষ্টা করুন।
- **রান্নাঘরে গিয়ে প্র্যাকটিস করুন:** রান্নাঘরের জিনিসগুলো দেখে দেখে ইংরেজি নাম বলুন।
