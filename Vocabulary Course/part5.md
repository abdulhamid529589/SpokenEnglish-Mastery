## 1. Abhor — ঘৃণা করা

| Feature             | Details                                           |
| ------------------- | ------------------------------------------------- |
| **Word**            | Abhor                                             |
| **Pronunciation**   | অ্যাব-হর (ab-HOR)                                 |
| **বাংলা অর্থ**      | তীব্র ঘৃণা করা, অত্যন্ত অপছন্দ করা                |
| **English Meaning** | To hate or dislike something extremely and deeply |
| **Word Type**       | Verb (ক্রিয়া)                                    |
| **Intensity**       | Much stronger than "hate" — গভীর ও তীব্র ঘৃণা     |

**Example Sentences | উদাহরণ বাক্য:**

| English                                  | বাংলা                                         |
| ---------------------------------------- | --------------------------------------------- |
| "I **abhor** cockroaches."               | "আমি আরশোলাকে তীব্রভাবে **ঘৃণা করি**।"        |
| "She **abhors** dishonesty in any form." | "সে যেকোনো ধরনের অসততাকে **ঘৃণা করে**।"       |
| "He **abhors** wasting food."            | "সে খাবার নষ্ট করাকে **অত্যন্ত অপছন্দ করে**।" |

**Comparison | তুলনা:**

| Word      | Strength                        | বাংলা          |
| --------- | ------------------------------- | -------------- |
| Dislike   | Mild — হালকা                    | পছন্দ না করা   |
| Hate      | Strong — শক্তিশালী              | ঘৃণা করা       |
| **Abhor** | Very strong — অত্যন্ত শক্তিশালী | তীব্র ঘৃণা করা |

**Memory Trick | মনে রাখার কৌশল:**

> **Ab**hor = **Ab**solutely horrible feeling toward something.
> অত্যন্ত ভয়ংকর অনুভূতি = abhor

## 2. Vacillate — দ্বিধায় দুলতে থাকা

| Feature             | Details                                                                               |
| ------------------- | ------------------------------------------------------------------------------------- |
| **Word**            | Vacillate                                                                             |
| **Pronunciation**   | ভ্যাসিলেট (VAS-i-layt)                                                                |
| **বাংলা অর্থ**      | দ্বিধায় দুলতে থাকা, সিদ্ধান্ত নিতে না পারা                                           |
| **English Meaning** | To keep changing your opinion or decision; to be unable to choose between two options |
| **Word Type**       | Verb (ক্রিয়া)                                                                        |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                                 | বাংলা                                                                      |
| ----------------------------------------------------------------------- | -------------------------------------------------------------------------- |
| "The tough case made the judge **vacillate** between the two verdicts." | "কঠিন মামলাটি বিচারককে দুটি রায়ের মধ্যে **দ্বিধায় দুলতে** বাধ্য করল।"    |
| "She **vacillated** for weeks before choosing a university."            | "বিশ্ববিদ্যালয় বেছে নেওয়ার আগে সে সপ্তাহের পর সপ্তাহ **দ্বিধায় দুলল**।" |
| "Stop **vacillating** and make a decision!"                             | "**দ্বিধা করা** বন্ধ করো এবং একটি সিদ্ধান্ত নাও!"                          |

**Visual | চিত্র:**

```
Option A ←→ Option B
    ↑ vacillating ↑
(going back and forth, unable to decide)
(এদিক-ওদিক দুলতে থাকা, সিদ্ধান্ত নিতে না পারা)
```

**Memory Trick | মনে রাখার কৌশল:**

> **Vacillate** sounds like **oscillate** (দোলানো) — going back and forth like a pendulum.
> দোল খাওয়া = vacillate — সিদ্ধান্তে দোল খাওয়া

## 3. Abscond — পালিয়ে যাওয়া

| Feature             | Details                                                                        |
| ------------------- | ------------------------------------------------------------------------------ |
| **Word**            | Abscond                                                                        |
| **Pronunciation**   | অ্যাব-স্কন্ড (ab-SKOND)                                                        |
| **বাংলা অর্থ**      | গোপনে পালিয়ে যাওয়া, লুকিয়ে পালানো                                           |
| **English Meaning** | To leave secretly and suddenly, usually to escape from the law or consequences |
| **Word Type**       | Verb (ক্রিয়া)                                                                 |
| **Common context**  | Crime, law, escape — অপরাধ, আইন, পলায়ন                                        |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                 | বাংলা                                            |
| ------------------------------------------------------- | ------------------------------------------------ |
| "The suspect **absconded** to Canada."                  | "সন্দেহভাজন ব্যক্তি কানাডায় **পালিয়ে গেল**।"   |
| "The employee **absconded** with company funds."        | "কর্মচারী কোম্পানির অর্থ নিয়ে **পালিয়ে গেল**।" |
| "The criminal **absconded** before the police arrived." | "পুলিশ আসার আগেই অপরাধী **গোপনে পালিয়ে গেল**।"  |

**Comparison | তুলনা:**

| Word        | বাংলা                | Nuance                                     |
| ----------- | -------------------- | ------------------------------------------ |
| Run away    | পালিয়ে যাওয়া       | General / সাধারণ                           |
| Escape      | মুক্তি পাওয়া        | From confinement / বন্দিত্ব থেকে           |
| **Abscond** | গোপনে পালিয়ে যাওয়া | Secretly, to avoid law / গোপনে, আইন এড়াতে |

**Memory Trick | মনে রাখার কৌশল:**

> **Ab**scond = **Ab**solutely gone — secretly disappeared.
> সম্পূর্ণ গায়েব = abscond

## 4. Enervate — শক্তিহীন করা

| Feature             | Details                                               |
| ------------------- | ----------------------------------------------------- |
| **Word**            | Enervate                                              |
| **Pronunciation**   | এনার্ভেট (EN-er-vayt)                                 |
| **বাংলা অর্থ**      | শক্তিহীন করা, দুর্বল করা, ক্লান্ত করে ফেলা            |
| **English Meaning** | To make someone feel weak, drained, or lacking energy |
| **Word Type**       | Verb (ক্রিয়া)                                        |

**Example Sentences | উদাহরণ বাক্য:**

| English                                               | বাংলা                                                          |
| ----------------------------------------------------- | -------------------------------------------------------------- |
| "The long presentation **enervated** me."             | "দীর্ঘ উপস্থাপনাটি আমাকে **শক্তিহীন করে ফেলল**।"               |
| "The extreme heat **enervated** all the workers."     | "তীব্র গরম সব কর্মীকে **দুর্বল করে দিল**।"                     |
| "Months of illness had **enervated** him completely." | "কয়েক মাসের অসুস্থতা তাকে সম্পূর্ণ **শক্তিহীন করে ফেলেছিল**।" |

**⚠️ Common Confusion | সাধারণ বিভ্রান্তি:**

> **Enervate** does NOT mean "energize" (শক্তি দেওয়া) — it means the **opposite**: to drain energy.
> অনেকে মনে করে enervate মানে শক্তি দেওয়া — আসলে এর **বিপরীত**: শক্তি কেড়ে নেওয়া।

**Memory Trick | মনে রাখার কৌশল:**

> **En**ervate = **En**ergy **e**vacuated — your energy is taken away.
> শক্তি উড়ে যাওয়া = enervate

## 5. Amplify — বিবর্ধিত করা / বাড়ানো

| Feature             | Details                                                                              |
| ------------------- | ------------------------------------------------------------------------------------ |
| **Word**            | Amplify                                                                              |
| **Pronunciation**   | অ্যাম্পলিফাই (AM-pli-fy)                                                             |
| **বাংলা অর্থ**      | বৃদ্ধি করা, আরও শক্তিশালী বা কার্যকর করা                                             |
| **English Meaning** | To increase, strengthen, or make something more effective; also to expand on an idea |
| **Word Type**       | Verb (ক্রিয়া)                                                                       |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                           | বাংলা                                                       |
| ----------------------------------------------------------------- | ----------------------------------------------------------- |
| "Proper maintenance of a routine **amplified** his productivity." | "রুটিন সঠিকভাবে মেনে চলায় তার উৎপাদনশীলতা **বৃদ্ধি পেল**।" |
| "The microphone **amplifies** your voice."                        | "মাইক্রোফোন তোমার কণ্ঠস্বর **বিবর্ধিত করে**।"               |
| "Exercise **amplifies** your mental focus."                       | "ব্যায়াম তোমার মানসিক মনোযোগ **বাড়িয়ে দেয়**।"           |

**Contexts where "amplify" is used | "amplify" যেসব ক্ষেত্রে ব্যবহার হয়:**

| Context                    | Example                                    |
| -------------------------- | ------------------------------------------ |
| Sound (শব্দ)               | Amplify music (সংগীত বিবর্ধিত করা)         |
| Productivity (উৎপাদনশীলতা) | Amplify output (ফলাফল বাড়ানো)             |
| Ideas (ধারণা)              | Amplify a point (একটি বিষয় বিস্তারিত করা) |
| Signal (সংকেত)             | Amplify a signal (সংকেত শক্তিশালী করা)     |

**Memory Trick | মনে রাখার কৌশল:**

> **Ampl**ify = **Ampl**e (প্রচুর) + ify = to make something ample/more.
> প্রচুর করা = amplify

## 6. Aggrandize — অতিরঞ্জিত করা / বড় করে দেখানো

| Feature             | Details                                                                               |
| ------------------- | ------------------------------------------------------------------------------------- |
| **Word**            | Aggrandize                                                                            |
| **Pronunciation**   | অ্যাগ্র্যান্ডাইজ (uh-GRAN-dyze)                                                       |
| **বাংলা অর্থ**      | নিজেকে বা কাউকে বাস্তবের চেয়ে বড় করে দেখানো, অতিরঞ্জিত করা                          |
| **English Meaning** | To make someone appear more important, powerful, or impressive than they actually are |
| **Word Type**       | Verb (ক্রিয়া)                                                                        |
| **Tone**            | Negative — নেতিবাচক (implies exaggeration / অতিরঞ্জন বোঝায়)                          |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                      | বাংলা                                                       |
| ------------------------------------------------------------ | ----------------------------------------------------------- |
| "She often **aggrandizes** herself in front of her friends." | "সে প্রায়ই বন্ধুদের সামনে নিজেকে **বড় করে দেখায়**।"      |
| "The politician tried to **aggrandize** his achievements."   | "রাজনীতিবিদ তার অর্জনগুলো **অতিরঞ্জিত করার** চেষ্টা করলেন।" |
| "He always **aggrandizes** his role in the team's success."  | "সে সবসময় দলের সাফল্যে তার ভূমিকা **বাড়িয়ে বলে**।"       |

**Memory Trick | মনে রাখার কৌশল:**

> **Aggrand**ize = **Grand** = making yourself seem grand (মহান) beyond reality.
> নিজেকে অতিরিক্ত মহান দেখানো = aggrandize

## 7. Espouse — সমর্থন করা / গ্রহণ করা

| Feature             | Details                                                       |
| ------------------- | ------------------------------------------------------------- |
| **Word**            | Espouse                                                       |
| **Pronunciation**   | ইস্পাউজ (ih-SPOWZ)                                            |
| **বাংলা অর্থ**      | কোনো ধারণা বা বিশ্বাস সমর্থন করা বা গ্রহণ করা                 |
| **English Meaning** | To adopt, support, or advocate for a belief, cause, or theory |
| **Word Type**       | Verb (ক্রিয়া)                                                |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                            | বাংলা                                                          |
| ------------------------------------------------------------------ | -------------------------------------------------------------- |
| "The new theory has been **espoused** by many leading scientists." | "নতুন তত্ত্বটি অনেক শীর্ষস্থানীয় বিজ্ঞানী **সমর্থন করেছেন**।" |
| "She has always **espoused** the cause of gender equality."        | "সে সবসময় লিঙ্গ সমতার কারণ **সমর্থন করে আসছে**।"              |
| "The party **espouses** traditional values."                       | "দলটি ঐতিহ্যবাহী মূল্যবোধ **সমর্থন করে**।"                     |

**Memory Trick | মনে রাখার কৌশল:**

> **Espouse** contains **spouse** (স্বামী/স্ত্রী) — you commit to an idea like you commit to a spouse.
> বিয়ে করার মতো কোনো ধারণাকে আঁকড়ে ধরা = espouse

## 8. Imbibe — আত্মস্থ করা / শোষণ করা

| Feature             | Details                                                                     |
| ------------------- | --------------------------------------------------------------------------- |
| **Word**            | Imbibe                                                                      |
| **Pronunciation**   | ইম-বাইব (im-BYB)                                                            |
| **বাংলা অর্থ**      | জ্ঞান বা ধারণা আত্মস্থ করা, শোষণ করা, মনের মধ্যে ধারণ করা                   |
| **English Meaning** | To absorb knowledge, ideas, or values deeply; also literally means to drink |
| **Word Type**       | Verb (ক্রিয়া)                                                              |

**Example Sentences | উদাহরণ বাক্য:**

| English                                                                                | বাংলা                                                                                         |
| -------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------- |
| "Visiting museums helped me **imbibe** the lessons from our rich history and culture." | "জাদুঘর পরিদর্শন আমাকে আমাদের সমৃদ্ধ ইতিহাস ও সংস্কৃতির শিক্ষা **আত্মস্থ করতে** সাহায্য করল।" |
| "Children **imbibe** values from their parents."                                       | "শিশুরা তাদের বাবা-মার কাছ থেকে মূল্যবোধ **আত্মস্থ করে**।"                                    |
| "He **imbibed** the company's culture quickly."                                        | "সে দ্রুত কোম্পানির সংস্কৃতি **আত্মস্থ করে নিল**।"                                            |

**Memory Trick | মনে রাখার কৌশল:**

> **Imbibe** = **Im**port + **bibe** (drink in Latin) = to drink in knowledge.
> জ্ঞান পান করা (পান করার মতো শোষণ করা) = imbibe

## 9. Acquiesce — অনিচ্ছায় সম্মত হওয়া

| Feature             | Details                                                                                     |
| ------------------- | ------------------------------------------------------------------------------------------- |
| **Word**            | Acquiesce                                                                                   |
| **Pronunciation**   | অ্যাকুইয়েস (ak-wee-ES)                                                                     |
| **বাংলা অর্থ**      | মন থেকে না চাইলেও বিনা প্রতিবাদে রাজি হওয়া, নীরবে মেনে নেওয়া                              |
| **English Meaning** | To accept or agree to something without objecting, even if you are not fully happy about it |
| **Word Type**       | Verb (ক্রিয়া)                                                                              |

## How to Remember Advanced Verbs | উন্নত ক্রিয়াপদ মনে রাখার উপায়

Repeat the pronunciation 3 times. Your mouth remembers what your brain forgets.
উচ্চারণ ৩ বার জোরে বলুন। আপনার মুখ সেটা মনে রাখে যা আপনার মস্তিষ্ক ভুলে যায়।
