### ১. Bulb / Light Bulb — বৈদ্যুতিক বাল্ব

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                          |
| --------------- | ------------------------------ |
| **ইংরেজি শব্দ** | Bulb / Light Bulb              |
| **উচ্চারণ**     | বাল্ব / লাইট বাল্ব             |
| **বাংলা অর্থ**  | বৈদ্যুতিক বাল্ব / বিদ্যুৎ বাতি |
| **বিকল্প শব্দ** | Light Bulb (আরও নির্দিষ্ট)     |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Bulb** বা **Light Bulb** হলো বৈদ্যুতিক আলো তৈরির কাচের গোলাকার যন্ত্র যা ঘর আলোকিত করে।

A **bulb** or **light bulb** is a glass device that produces light using electricity. It is the most common source of light in homes and offices.

**বাল্বের ধরন | Types of Bulbs:**

| ইংরেজি            | বাংলা        | বৈশিষ্ট্য                     |
| ----------------- | ------------ | ----------------------------- |
| Incandescent bulb | সাধারণ বাল্ব | পুরনো ধরনের, বেশি বিদ্যুৎ খরচ |
| LED bulb          | এলইডি বাল্ব  | কম বিদ্যুৎ খরচ, বেশি টেকসই    |
| CFL bulb          | সিএফএল বাল্ব | পেঁচানো আকৃতি                 |
| Tube light        | টিউব লাইট    | লম্বা, সাদা আলো               |

> 📌 **মনে রাখুন:** বাংলায় আমরা সাধারণত "বাল্ব" বলি — ইংরেজিতেও **Bulb** বা **Light Bulb** বলা যায়।

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** The room is well lit with a big **bulb** and a tube light.
> **বাংলা:** একটি বড় **বাল্ব** এবং একটি টিউব লাইটের সাহায্যে ডাইনিং রুমটি খুব ভালোভাবে আলোকিত।

### ২. Tube Light — টিউব লাইট

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                |
| --------------- | ------------------------------------ |
| **ইংরেজি শব্দ** | Tube Light                           |
| **উচ্চারণ**     | টিউব লাইট                            |
| **বাংলা অর্থ**  | টিউব লাইট (লম্বা আকৃতির বাতি)        |
| **বিকল্প শব্দ** | Fluorescent Light / Fluorescent Tube |
| **বিশেষ নোট**   | এই শব্দটি পরিবর্তন না করাই ভালো      |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Tube Light** হলো লম্বা, সরু, সাদা আলোর বাতি। বাংলায় যেমন "টিউব লাইট" বলা হয়, ইংরেজিতেও **Tube Light** বলা যায়।

A **tube light** is a long, cylindrical fluorescent lamp that emits bright white light. In technical English, it is called a **fluorescent tube** or **fluorescent light**.

> ⚠️ **গুরুত্বপূর্ণ নোট | Important Note:**
> ভিডিওতে বলা হয়েছে — **Tube Light** শব্দটি অন্য কিছু দিয়ে প্রতিস্থাপন না করাই ভালো, কারণ বিভ্রান্তি তৈরি হতে পারে। **Tube Light** বলুন এবং সবাই বুঝবে।

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** The room is well lit with a big bulb and a **tube light**.
> **বাংলা:** একটি বড় বাল্ব এবং একটি **টিউব লাইটের** সাহায্যে ঘরটি খুব ভালোভাবে আলোকিত।

### ৩. Tablecloth — টেবিলের কাপড়

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                        |
| --------------- | ---------------------------- |
| **ইংরেজি শব্দ** | Tablecloth                   |
| **উচ্চারণ**     | টেবিলক্লথ                    |
| **বাংলা অর্থ**  | টেবিলের উপর বিছানো বড় কাপড় |
| **বিকল্প শব্দ** | Table Cover                  |
| **বিশেষত্ব**    | পুরো টেবিল ঢেকে রাখে         |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Tablecloth** হলো পুরো ডাইনিং টেবিলের উপর বিছানো বড় কাপড় যা টেবিলকে সুরক্ষিত ও সুন্দর রাখে।

A **tablecloth** is a large piece of fabric that covers the entire surface of a dining table. It protects the table and adds a decorative touch.

**Tablecloth সম্পর্কিত বিশেষণ | Related Adjectives:**

- **Green tablecloth** = সবুজ টেবিলক্লথ
- **Linen tablecloth** = লিনেন কাপড়ের টেবিলক্লথ
- **Embroidered tablecloth** = সুই-সুতার কাজ করা টেবিলক্লথ

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Right in the middle of our room is our big family dining table with my mother's favorite green **tablecloth**.
> **বাংলা:** আমাদের ঘরের ঠিক মাঝখানে আমাদের বড় পারিবারিক ডাইনিং টেবিলটি আছে, যাতে আমার মায়ের পছন্দের সবুজ **টেবিলক্লথ** বিছানো।

### ৪. Table Mat / Place Mat — টেবিল ম্যাট

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                  |
| --------------- | -------------------------------------- |
| **ইংরেজি শব্দ** | Table Mat / Place Mat                  |
| **উচ্চারণ**     | টেবিল ম্যাট / প্লেস ম্যাট              |
| **বাংলা অর্থ**  | ছোট ম্যাট, প্লেটের নিচে রাখা হয়       |
| **বিকল্প শব্দ** | Coaster (গ্লাসের নিচে রাখার ছোট ম্যাট) |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Table Mat** বা **Place Mat** হলো ছোট আকারের ম্যাট যা প্রতিটি ব্যক্তির খাবারের জায়গায় প্লেটের নিচে রাখা হয়।

A **table mat** or **place mat** is a small mat placed under each person's plate at the dining table to protect the tablecloth from heat, stains, and scratches.

**বিশেষ নোট | Special Note:**

| শব্দ                      | বাংলা             | ব্যবহার                      |
| ------------------------- | ----------------- | ---------------------------- |
| **Tablecloth**            | বড় টেবিল কাপড়   | পুরো টেবিল ঢাকে              |
| **Table Mat / Place Mat** | ছোট ম্যাট         | একজনের জায়গা ঢাকে           |
| **Coaster**               | গোলাকার ছোট ম্যাট | গ্লাস বা কাপের নিচে রাখা হয় |

### ৫. Fruit Bowl — ফলের বাটি

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                       |
| --------------- | --------------------------- |
| **ইংরেজি শব্দ** | Fruit Bowl                  |
| **উচ্চারণ**     | ফ্রুট বোল                   |
| **বাংলা অর্থ**  | ফলের বাটি / ফলদানি          |
| **বিকল্প শব্দ** | Fruit Holder / Fruit Basket |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Fruit Bowl** হলো ফল রাখার বাটি বা পাত্র যা সাধারণত ডাইনিং টেবিলের উপর সাজিয়ে রাখা হয়।

A **fruit bowl** is a bowl or decorative container used to hold and display fruits on the dining or kitchen table.

**Bowl সম্পর্কিত শব্দ | Bowl-Related Vocabulary:**

| ইংরেজি      | বাংলা        |
| ----------- | ------------ |
| Fruit bowl  | ফলের বাটি    |
| Salad bowl  | সালাদের বাটি |
| Soup bowl   | স্যুপের বাটি |
| Mixing bowl | মিশানোর বাটি |
| Sugar bowl  | চিনির বাটি   |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** On the table is a **fruit bowl**, some cutleries, plates and glasses.
> **বাংলা:** টেবিলের উপর একটি **ফলের বাটি**, কিছু চামচ-কাঁটা, প্লেট এবং গ্লাস আছে।

### ৬. Cutlery — চামচ-কাঁটা-ছুরি

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                                    |
| --------------- | -------------------------------------------------------- |
| **ইংরেজি শব্দ** | Cutlery                                                  |
| **উচ্চারণ**     | কাটলারি                                                  |
| **বাংলা অর্থ**  | চামচ, কাঁটা ও ছুরি — এই তিনটি একসাথে                     |
| **বিকল্প শব্দ** | Silverware / Flatware (আমেরিকান ইংরেজি)                  |
| **বিশেষত্ব**    | Cutlery = সংগ্রহ বোঝায়, তাই plural "cutleries" বলা যায় |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Cutlery** হলো ডাইনিং টেবিলে ব্যবহৃত ধাতব হাতিয়ার — চামচ (spoon), কাঁটা (fork) এবং ছুরি (knife) — এই তিনটি একত্রে।

**Cutlery** refers collectively to the knives, forks, and spoons used at the dining table. In American English, it is often called **silverware** or **flatware**.

**Cutlery-এর অংশ | Parts of Cutlery:**

| ইংরেজি        | বাংলা        | ব্যবহার               |
| ------------- | ------------ | --------------------- |
| Spoon         | চামচ         | তরল বা নরম খাবার খেতে |
| Fork          | কাঁটা চামচ   | কঠিন খাবার ধরতে       |
| Knife         | ছুরি         | কাটতে                 |
| Dessert spoon | মিষ্টির চামচ | ছোট আকারের চামচ       |
| Teaspoon      | চায়ের চামচ  | সবচেয়ে ছোট           |
| Tablespoon    | বড় চামচ     | পরিবেশনের জন্য        |

> 📌 **মনে রাখুন:** "Cutlery" শব্দটি সংগ্রহ (collection) বোঝায়, তাই এটি সাধারণত singular রূপে ব্যবহৃত হয়।
> ✅ "some cutlery" — সঠিক
> ✅ "cutleries" — ভিডিওতে বলা হয়েছে, এটিও গ্রহণযোগ্য

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** On the table is a fruit bowl, some **cutleries**, plates and glasses.
> **বাংলা:** টেবিলের উপর একটি ফলের বাটি, কিছু **চামচ-কাঁটা-ছুরি**, প্লেট এবং গ্লাস আছে।

### ৭. Plates — থালা / প্লেট

| **বিকল্প শব্দ** | Dishes       |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Plates** হলো খাবার পরিবেশন ও খাওয়ার জন্য চ্যাপ্টা গোলাকার পাত্র।

**Plates** are flat, round dishes used for serving and eating food.

### ৮. Glass / Drinking Glass — গ্লাস / পানির গ্লাস

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                        |
| --------------- | ---------------------------- |
| **ইংরেজি শব্দ** | Glass / Drinking Glass       |
| **উচ্চারণ**     | গ্লাস / ড্রিংকিং গ্লাস       |
| **বাংলা অর্থ**  | পানির গ্লাস / পানীয়ের পাত্র |
| **বিকল্প শব্দ** | Tumbler / Cup                |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Glass** বা **Drinking Glass** হলো পানি বা পানীয় পান করার কাচের পাত্র।

A **glass** (or **drinking glass**) is a container made of glass or other material used for drinking water or beverages.

> ⚠️ **বিভ্রান্তি এড়ান | Avoid Confusion:**
>
> - **Glass** (উপাদান) = কাচ (material: windows are made of glass)
> - **Glass** (পাত্র) = পানির গ্লাস (drinking vessel)
>   প্রসঙ্গ বুঝে ব্যবহার করুন!

**পানীয় পাত্রের ধরন | Types of Drinking Vessels:**

| ইংরেজি                   | বাংলা        | বৈশিষ্ট্য                   |
| ------------------------ | ------------ | --------------------------- |

| Cup                      | কাপ          | ছোট, সাধারণত চায়ের জন্য    |
| Wine glass               | ওয়াইন গ্লাস | সরু ডাঁটি আছে               |
| Jug / Pitcher            | জগ           | পানি ঢালার বড় পাত্র        |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** On the table is a fruit bowl, some cutleries, plates and **glasses**.
> **বাংলা:** টেবিলের উপর একটি ফলের বাটি, কিছু চামচ-কাঁটা, থালা এবং **গ্লাস** আছে।

### ৯. Napkin — ন্যাপকিন / রুমাল

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                          |
| --------------- | ------------------------------ |
| **ইংরেজি শব্দ** | Napkin                         |
| **উচ্চারণ**     | ন্যাপকিন                       |
| **বাংলা অর্থ**  | ন্যাপকিন / খাবার টেবিলের রুমাল |
| **বিকল্প শব্দ** | Handkerchief / Serviette       |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Napkin** হলো ছোট কাপড় বা কাগজ যা খাওয়ার সময় মুখ ও হাত মোছার জন্য ব্যবহার করা হয়। এটিকে **Handkerchief** বলা যায়, তবে পার্থক্য আছে।

A **napkin** is a small piece of cloth or paper used to wipe the mouth and hands during a meal. It can also be called a **handkerchief** or **serviette** (British English).

**Napkin বনাম Handkerchief | Napkin vs Handkerchief:**

| বিষয়    | Napkin        | Handkerchief    |
| -------- | ------------- | --------------- |
| ব্যবহার  | খাবার টেবিলে  | পকেটে রাখা যায় |
| উপাদান   | কাপড় বা কাগজ | কাপড়           |
| আকার     | বড় বা ছোট    | সাধারণত ছোট     |
| অনুষ্ঠান | ডাইনিং টেবিলে | যেকোনো সময়     |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** My father's chair always has a red **napkin** on which he wipes his hands after eating.
> **বাংলা:** আমার বাবার চেয়ারে সবসময় একটি লাল **ন্যাপকিন** থাকে যা দিয়ে তিনি খাওয়ার পরে হাত মোছেন।

### ১০. Fridge / Refrigerator — ফ্রিজ

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                                  |
| --------------- | -------------------------------------- |
| **ইংরেজি শব্দ** | Fridge                                 |
| **উচ্চারণ**     | ফ্রিজ                                  |
| **বাংলা অর্থ**  | ফ্রিজ / শীতলীকরণ যন্ত্র                |
| **পূর্ণ শব্দ**  | Refrigerator (রেফ্রিজারেটর)            |
| **সম্পর্ক**     | Fridge = Refrigerator-এর সংক্ষিপ্ত রূপ |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Fridge** হলো **Refrigerator**-এর সংক্ষিপ্ত (informal) রূপ। উভয়ই সঠিক এবং ব্যাপকভাবে ব্যবহৃত।

**Fridge** is the short, informal form of **refrigerator**. Both words refer to the same appliance — a machine used to keep food and drinks cold and fresh.

**ফ্রিজ সম্পর্কিত শব্দ | Fridge-Related Vocabulary:**

- **Freezer** = ফ্রিজের হিমায়ক অংশ (frozen section)
- **Chill** = ঠান্ডা করা
- **Defrost** = বরফ গলানো
- **Fridge magnet** = ফ্রিজে লাগানো চুম্বক

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Our **fridge** and microwave are also in the dining room.
> **বাংলা:** আমাদের **ফ্রিজ** এবং মাইক্রোওয়েভও ডাইনিং রুমে আছে।

### ১১. Microwave / Oven — মাইক্রোওয়েভ / ওভেন

#### 📖 সংজ্ঞা | Definition

| বিষয়           | বিবরণ                         |
| --------------- | ----------------------------- |
| **ইংরেজি শব্দ** | Microwave                     |
| **উচ্চারণ**     | মাইক্রোওয়েভ                  |
| **বাংলা অর্থ**  | মাইক্রোওয়েভ / বৈদ্যুতিক ওভেন |
| **বিকল্প শব্দ** | Oven / Microwave Oven         |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Microwave** হলো একটি বৈদ্যুতিক রান্নার যন্ত্র যা তড়িৎচুম্বকীয় তরঙ্গ ব্যবহার করে খাবার গরম করে বা রান্না করে।

A **microwave** (or **microwave oven**) is an electric appliance that uses electromagnetic waves to heat or cook food quickly. It is commonly called an **oven** in everyday speech.

**Microwave বনাম Oven | Microwave vs Oven:**

| বিষয়   | Microwave             | Oven                   |
| ------- | --------------------- | ---------------------- |
| তাপ উৎস | মাইক্রোওয়েভ তরঙ্গ    | বৈদ্যুতিক বা গ্যাস তাপ |
| সময়    | খুব দ্রুত             | ধীরে                   |
| ব্যবহার | গরম করা, দ্রুত রান্না | বেক করা, ধীরে রান্না   |
| আকার    | সাধারণত ছোট           | বড় হতে পারে           |

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** Our fridge and **microwave** are also in the dining room.
> **বাংলা:** আমাদের ফ্রিজ এবং **মাইক্রোওয়েভ**ও ডাইনিং রুমে আছে।

#### 📖 সংজ্ঞা | Definition

| বিষয়            | বিবরণ                                             |
| ---------------- | ------------------------------------------------- |
| **ইংরেজি শব্দ**  | Sink                                              |

| **বাংলা অর্থ**   | বেসিন / হাত ধোয়ার জায়গা                         |
| **বিকল্প শব্দ**  | Basin / Washbasin                                 |
| **পাঠ ১৯ সংযোগ** | Kitchen Sink (রান্নাঘরে) — এখানে Dining Room Sink |

#### 💡 বিস্তারিত ব্যাখ্যা | Explanation

**Sink** হলো হাত ধোয়া বা পানি ব্যবহারের জন্য বেসিন। ডাইনিং রুমে এটি খাওয়ার আগে ও পরে হাত ধোয়ার জন্য থাকে।

A **sink** is a fixed basin with running water used for washing hands, dishes, or vegetables. In a dining room context, it is used for washing hands before and after meals.

> 🔗 **পাঠ ১৯-এর সাথে সংযোগ:** রান্নাঘরে এটিকে **Kitchen Sink** বলা হয়েছিল। এটি একই ধরনের জিনিস — শুধু অবস্থান আলাদা।

#### ✍️ উদাহরণ বাক্য | Example Sentence

> **English:** So is a **sink** for everyone to wash their hands.
> **বাংলা:** সবার হাত ধোয়ার জন্য একটি **বেসিন**ও আছে।

## মনে রাখার কৌশল | Memory Tips

### 🧠 শব্দ মনে রাখার সহজ উপায়

| শব্দ           | মনে রাখার কৌশল                                              |
| -------------- | ----------------------------------------------------------- |
| **Bulb**       | বাংলায় "বাল্ব" — একই উচ্চারণ!                              |
| **Tube Light** | পরিবর্তন না করে সরাসরি "Tube Light" বলুন                    |
| **Tablecloth** | Table (টেবিল) + Cloth (কাপড়) = টেবিলের কাপড়               |
| **Fruit Bowl** | Fruit (ফল) + Bowl (বাটি) = ফলের বাটি                        |
| **Cutlery**    | "Cut" আছে — কাটার সরঞ্জাম (ছুরি, কাঁটা, চামচ)               |
| **Napkin**     | "ন্যাপকিন" — বাংলায়ও এভাবেই বলা হয়                        |
| **Fridge**     | Refrigerator → সংক্ষেপে "Fridge"                            |
| **Microwave**  | Micro (ক্ষুদ্র) + Wave (তরঙ্গ) = ক্ষুদ্র তরঙ্গ দিয়ে রান্না |
| **Sink**       | "Sink" = ডুবে যাওয়া → পানি নামে যে বেসিনে                  |

### 🔑 মূল নীতি | Key Principles

- কিছু শব্দ বাংলায়ও একই আছে — **Bulb**, **Tube Light**, **Fridge**, **Microwave**, **Napkin** — এগুলো সহজে মনে থাকবে।
- **Cutlery** = Spoon + Fork + Knife মিলিয়ে একটি শব্দ — তিনটি আলাদা না বলে একসাথে বলুন।
- **Tablecloth** ও **Table Mat** এর পার্থক্য মনে রাখুন — বড় vs ছোট।
